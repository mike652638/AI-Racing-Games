# src/game/

## Responsibility

游戏编排（game orchestration）层：在 `engine/`（伪 3D 渲染与赛道数据）与 `physics/`（车辆运动学）之上，编排一局完整比赛的全部运行时职责。M6/M7 重构后，原先散落在 `main.ts` 的 DOM 引用、初始化、赛道切换、流程控制、事件监听与每帧更新/渲染编排全部下沉至此，`main.ts` 只保留一行入口调用。本目录承担七类职责：

- **主循环**（`game-loop.ts`）：`GameLoop` 编排壳持有全部运行时引用（DOM、渲染器、输入、音频、状态），驱动每帧更新/渲染/自续与阶段流转，并编排四种游玩模式（单屏 / `?split` 分屏双键盘 / `?hotseat` 热座轮流 / `?challenge` 挑战限时刷分）；另导出 `initGame` 入口与 `updatePlayerFrame` 等纯函数 re-export（实现迁至 `frame-pure.ts`，同名 re-export 保持外部 `'game-loop'` import 路径兼容）。**M15 架构重构**：每帧更新/渲染下沉 `frame-update.ts`/`frame-render.ts` 纯函数、四模式差异下沉 `mode-strategy.ts` 策略对象、结算记账下沉 `finish-accounting.ts`（938→719 行）；**M16/M17 运行时实测修复与菜单增强、M18 UI/UX 深度打磨后恢复增长至 1031 行**（`ensureLoop` 幂等 RAF 调度、`silenceDriveSounds` 静音修复、`syncRendererTrack` 缓存激活、赛道缩略图/模式徽章、屏幕过渡/触屏引导等）；**M34 第二轮瘦身（2026-08-15，1490→1133 行）**：六组逻辑下沉为带单测的兄弟模块——URL 模式解析（`game-params.ts`）、菜单静态装饰装配（`menu-setup.ts`）、路线模式集中化（`route-choice.ts`，逻辑原散落五处收敛为单一真源）、BOOST 未蓄能红闪（`boost-feedback.ts`）、赛道卡构建（`track-cards.ts`）、暂停控件绑定（`pause-controls.ts`）；另加 `shared/timer.ts` unrefSafeTimeout 收敛两处重复计时、`ui/screens.ts` applyPauseBranding/revealRacingTouchHint、`top-refresh.ts` refreshMenuBoard 消重两处菜单刷新。M13 H 系列新增：H1 挑战计分加成（雨天/难度倍率）、H2 BOOST 音效与尾焰粒子、H4 漂移连击入榜、H5 lastLap 直返重构（移除 ref 桥接）、H6 碰撞音强度随速度。
- **状态容器**（`state.ts` / `player-state.ts`）：`RaceState` 集中管理双玩家可变状态、碰撞计数、圈速记录与双赛道上下文；`PlayerState` 为单玩家独立状态实例（含 M12 BOOST 蓄力）。`RaceState` 接口真源已提升至 `src/shared/types.ts`，`state.ts` 的类型 re-export 行已于 2026-08-22 剥离（仅保留 `createRaceState`/`resetRaceState` 工厂函数，类型经 import type 自 shared/types 引入）；**`PlayerState` 接口真源亦于 2026-08-15 提升**（消除 shared → game 的唯一类型反指，shared → game 零引用含类型层），`player-state.ts` 的类型 re-export 行亦已剥离（仅保留 `createPlayerState`/`resetPlayerState` 工厂函数）。
- **赛道世界**（`track-context.ts` / `track-manager.ts`）：`TrackContext` 封装单个玩家的完整赛道世界（分段/圈长/渲染预计算/车流）；`TrackManager` 按玩家索引持有双上下文并管理赛道切换。`TrackContext` 接口真源同样提升至 `src/shared/types.ts`，`track-context.ts` re-export。
- **碰撞裁决**（`collision.ts` / **M16 `collision-feedback.ts`**）：每帧检测玩家与其所在世界的车流碰撞，施加速度惩罚并维护冷却，结果写回 `RaceState`（分屏双人全检；热座按当前回合玩家参与）；M16 起 `applyTrafficCollision` 返回 `{ hit, impact, cooldown }`（impact 速度比），`collision-feedback.ts` 的 `updateCollisionFlash`/`flashSeedFromSpeedRatio` 维护红闪状态（命中重置 + 指数衰减）供渲染层屏幕红晕与 HUD 碰撞计数消费。2026-08-05 加 `RACE_START_GRACE` 起步保护期（raceTime < 5s 免疫碰撞，防倒计时期车流环绕穿越出生点误撞）。
- **阶段 FSM**（真源 `src/shared/phase`、`phase-logic`、`lap`）：阶段常量/类型、阶段转移纯函数（`nextPhase`/`togglePause`）与圈数计算（`lapFromZ`）唯一真源在 `src/shared/`；本目录不再保留兼容层（2026-08-22 移除），`phase.ts`/`phase-logic.ts`/`lap.ts` 文件已删除，game 内部直接导入 shared。
- **输入适配与基础件**（`input.ts` / `debug-hook.ts`）：键盘输入工厂、`window.__gameDebug` 调试钩子（32 个 getter，含热座回合/车流观测/主音量/雨声/挑战倒计时/BOOST 蓄力/**M16 碰撞红闪**/M23 天气与车流橡皮筋/M28 引导线与路线阶段/M32 分叉淡入与每日挑战 字段；生产构建剥离——非 DEV 直接 no-op，死码消除）；游戏参数常量直接导入 `src/shared/constants`（原 `constants.ts` re-export 兼容层已于 2026-08-22 移除）。
- **M15/M16 拆分件**（`mode-strategy.ts` / `finish-accounting.ts` / `frame-update.ts` / `frame-render.ts` / `frame-pure.ts` / `volume.ts` / `top-refresh.ts`）+ **2026-08-05 下沉件**（`audio-rig.ts` / `countdown.ts` / `dom-setup.ts` / `track-preview.ts`）+ **M34 拆分件（2026-08-15）**（`game-params.ts` / `menu-setup.ts` / `route-choice.ts` / `boost-feedback.ts` / `track-cards.ts` / `pause-controls.ts`）：见 Design 与 Files 表逐条职责。

## Design

- **TrackContext 双世界建模（split-screen worlds）**：每个玩家持有独立的 `TrackContext`（`def`/`segments`/`lapLength`/`totalLaps`/`curvePrefixSum`/`spriteIndex`/`sprites`/`roadStrips`/`traffic`），P1/P2 各建一份、互不共享，车流独立推进与碰撞；单人模式仅 `[0]` 生效。渲染预计算在 `createTrackContext` 创建时完成（`buildCurvePrefixSum`/`buildSpriteIndex`/`createRoadsideSprites`/M14 起 `buildRoadStrips` 曲率段预计算），运行时零重建；2026-08-05 起车流创建带 `TRAFFIC_SPAWN_SAFE_ZONE` 出生安全窗口（玩家出生点前方不生成车流，与 `RACE_START_GRACE` 配套防开局误撞）。车流密度由 `def.trafficCount ?? TRAFFIC_DEFAULT_COUNT` 决定；M17 起路边景物按 `getEnvironmentProfile(def.environment)` 差异化密度/树色/形状。
- **RaceState 集中可变状态 + 纯函数更新**：`RaceState` 是每帧数据流的唯一汇聚点，双玩家对称字段（`player1`/`player2`）、双世界 `tracks`、碰撞计数、圈速记录（`lapTimes`/`lastLap` 与分屏独立的 `lapTimes2`/`lastLap2`）全部集中于此，便于统一重置与单测。更新侧收敛为纯函数 `updatePlayerFrame`（漂移 → 速度修正 → 车辆运动学 → 相机推进 → 计时 → 圈数记录，实现迁至 `frame-pure.ts`），主循环按模式调用：非热座 P1/P2 各一次，热座仅当前回合玩家一次。
- **Renderer 多 view 渲染（零重建）**：`viewFor(ctx)`（`frame-pure.ts`，`_viewCache` 模块级单例复用）每次从 `TrackContext` 提取 `RenderView`（`{ track, curvePrefixSum, spriteIndex, traffic, night, environment, boostParticles?, speedRatio, boosting, steer, collisionFlash, playerIndex? }`）——只是对象字面量组合，无任何预计算重建；H2 起可选 `boostParticles`（BOOST 尾焰粒子数组，比赛渲染传、菜单预览不传），M16 起含 `collisionFlash`（碰撞红闪强度）与 `steer`（车辆转向倾斜），2026-08-05 起第 7 尾参 `playerIndex?: 1|2`（分屏 P2 传 2 → 蓝色车身）。分屏双世界渲染时分别取 `tracks[0]`/`tracks[1]` 的 view，配合 `renderRegion` 双区域 + `drawDivider` 交界分隔线；单屏与菜单预览走 `render`。
- **shared 解环（2026-08-05）与兼容层移除（2026-08-22）**：常量/阶段/圈数真源与 `RaceState`/`TrackContext` 类型提升至 `src/shared/` 后，本目录原 `constants.ts`（`export *`）、`phase.ts`、`phase-logic.ts`、`lap.ts` 纯 re-export 兼容层已于 2026-08-22 移除（文件删除），`state.ts`/`track-context.ts` 的类型 re-export 行亦已剥离（仅保留工厂函数）；**`ui/` 对 `game/` 已零依赖（含类型层）**——ui 的 RaceState/TrackContext 从 `../shared/types` 导入，常量从 `../shared/constants` 导入，运行时环与类型环均消除；game 对 ui 仍为运行级调用（hud/screens/joystick/save/minimap）。依赖方向单向：`engine/physics/ui → shared`，`game → shared + engine + physics + ui(运行级)`。
- **updatePlayerFrame 纯函数收敛双玩家逻辑（H5 直返 lastLap）**：`updatePlayerFrame(dt, input, player, carConfig, lapLength, lapTimes?, wet = false, scoreMultiplier = 1): number` 对 P1/P2 共用同一更新管线；`lapTimes` 可选——传入时以 `lapTimes.length + 1` 推断当前圈数（每次过圈 push 一条 `raceTime`），`currentLap > lapTimes.length + 1` 判定过圈，返回 `currentLap`；未传返回 1。**H5 重构**：原 `lastLapRef?: LastLapRef` 可变包装尾参与 G5 的 `lapRef`/`lapRef2` 复用字段全部移除，调用方直接单行赋值 `race.lastLap = updatePlayerFrame(...)`（P2 写 `race.lastLap2`），消除每帧对象分配、行为零变化。`wet`（G3 雨天物理）为第 6 尾参、`scoreMultiplier`（H1 挑战加成）为第 7 尾参，默认值下逐字节不变。
- **TrackManager 双玩家依赖注入**：`TrackManager` 构造时注入 `TrackManagerDeps`（`resetRace` 回调、双赛道名元素、`splitMode`、选单选项数组），内部持 `contexts: [TrackContext, TrackContext]` 双上下文与 `selectedIndexes`；`selectTrack` 重建该玩家上下文 → 触发 `resetRace` 回调 → 刷新选单双类高亮（P1 `selected` / P2 `selected-p2`，分屏时 aria-pressed 同步），另一玩家不受影响。**双引用同步点**：渲染与 HUD 取 `race.tracks`，权威上下文由 `TrackManager.contexts` 持有，`selectTrackFor` 把 `getContext(playerIndex)` 写回 `race.tracks[playerIndex]` 完成同步，并经 `syncRendererTrack` 把新上下文预计算推给 renderer `setTrack`（激活 road-strip 离屏缓存消费；node 测试环境无 OffscreenCanvas 时降级不带 roadStrips）。
- **M15 策略与纯函数下沉（架构重构，行为零变化）**：四游玩模式差异收敛为 `ModeStrategy` 策略对象（`mode-strategy.ts`：SINGLE/SPLIT/HOTSEAT/CHALLENGE 四实例 + `createModeStrategy` 工厂，URL 互斥判定仍留在 GameLoop 构造器，split 优先逻辑不变），GameLoop 内散落的 `splitMode || (hotseatMode && hotseatPlayer === 2)` 类分支全部替换为 `mode.xxx()` 调用（输入路由 `getInputs`/分屏活跃玩家 `updateActivePlayer`/车流推进 `shouldUpdateP2Traffic`/碰撞范围 `collisionIncludesP2`/玩家更新 `updatePlayers`/完赛判定 `shouldFinish`/选赛道同步 `afterSelectP1Track`/菜单提示 `menuHint`）；每帧更新段 `updateFrame` 与渲染段 `renderFrame` 从 GameLoop.frame 抽为纯函数模块（`frame-update.ts`/`frame-render.ts`），帧间状态经返回值写回（lastActivePlayer/boostActive/lastCollisionCount/collisionFlash/惰性 DOM 缓存），完赛触发返回 `shouldRender=false` 跳过渲染；结算记账（完赛判定/胜场/漂移/对局持久化）下沉 `finish-accounting.ts` 的 `accountFinish`（DOM 副作用 refreshDriftTop/refreshMatchTop/applyPhaseToScreens 留在 GameLoop）。game-loop.ts 由 938 行降至 719 行、无单方法超 80 行；**2026-08-05 补充**：`frame()` 渲染段转向输入采集（原内联 `mode.getInputs` 路由）下沉为 `mode-strategy.collectSteerInputs` 纯函数，与 updateFrame 内路由完全同源（消除重复实现）。
- **M15 纯函数/榜单/音量同步下沉**：`updatePlayerFrame`/`updateBoostCharge`/`viewFor`/`PREVIEW_CAMERA_SPEED`/`advancePreviewCameraZ`/`initialPreviewCameraZ` 与 `PerformanceConfig`/`resolvePerformanceConfig` 实现迁至 `frame-pure.ts`（game-loop 同名 re-export 保持外部 `'game-loop'` import 路径兼容）；音量持久化拆分 `volume.ts`（`VOLUME_KEY`/`MUSIC_VOLUME_KEY`/`SFX_VOLUME_KEY` 与默认值、`loadVolumeFromStorage`/`loadMusicVolumeFromStorage`/`loadSfxVolumeFromStorage`/`persistVolume`/`clampAndSyncGain`）；菜单榜单刷新拆分 `top-refresh.ts`（`refreshDriftTop`/`refreshBestSummary`/`refreshMatchTop`，均 document.getElementById 防御式访问，`isCardExpanded` 支持 .lb-card 收起/展开取 5 条或全量 10 条）；**M15 新增 `CHALLENGE_TARGET_SCORE = 5000` 挑战目标分数**（真源 shared/constants，ui/screens.ts 结算展示达标/未达标，挑战菜单提示「目标 5000」）；**M15 性能模式（`?perf=1`）**：`GameLoop._perfMode = params.has('perf')`，`getPerformanceConfig()` 委托纯函数 `resolvePerformanceConfig(splitMode, _perfMode)`（PERF_HIGH 120 段全特效默认 / PERF_MID 分屏 80 段跳过粒子特效 / PERF_LOW 60 段最激进降级，含 drawDistance/skipSmoke/skipBoostParticles/skipRain 开关）；与 split 不互斥（共存时性能档优先）。
- **2026-08-05 下沉件（自 game-loop 拆分）**：`audio-rig.ts` 的 `AudioRig`/`createAudioRig`（startGame 惰性装配：masterGain 总控 + musicGain/sfxGain 分轨 + EngineSound/Music/RainSound/CollisionSound/BoostSound/DriftSound/TireSound 全部音效一次性构建，引擎声与音乐立即 start 其余待帧驱动）；`countdown.ts` 的 `runCountdown(overlay, hints?)`（起步 3→2→1→GO 数字动画 + 操作提示同源填充——**2026-08-08 触屏适配：第 2 参 hints 由调用方按设备传入，键盘玩家用 `COUNTDOWN_HINTS`，单屏触屏用 `COUNTDOWN_HINTS_TOUCH`（摇杆指引）、分屏触屏用 `COUNTDOWN_HINTS_TOUCH_SPLIT`（四分区指引）**，800ms/档、GO 后 500ms 隐藏，元素缺失安全跳过）；`dom-setup.ts` 的 `collectHudElements`/`collectScreenElements`（构造期一次性 DOM 查询聚合，返回 `HudElements`/`ScreenElements`）；`track-preview.ts` 的 `integrateControlPoints`/`buildTrackPreviewSvg`（赛道控制点积分生成平面轨迹 + 归一化 SVG path，菜单中央信息区预览用，`color` 随环境取 `getEnvironmentPreviewColor` 并供 CSS 光晕）。
- **M34 第二轮下沉（2026-08-15，game-loop 1490→1133 行）**：延续 M15「纯函数 + 注入式 DOM」模式——`game-params.ts`（URL 模式解析纯函数）、`menu-setup.ts`（菜单静态装饰，getElement 注入）、`route-choice.ts`（路线模式五处散落逻辑收敛单一真源，状态字段仍留 GameLoop）、`boost-feedback.ts`（红闪纯状态机 + `shared/timer.ts` unrefSafeTimeout 收敛两处重复计时）、`track-cards.ts`（赛道卡 DOM + 网格导航纯函数）、`pause-controls.ts`（暂停控件注入式绑定）；`ui/screens.ts` 新增 `applyPauseBranding`（暂停标题按玩家标注 + 赛道名）与 `revealRacingTouchHint`（触屏引导，unrefSafeTimeout 计时）；`top-refresh.ts` 新增 `refreshMenuBoard`（构造器与回菜单两处同源刷新消重）。各模块均配独立单测（game-params/menu-setup/route-choice/boost-feedback/track-cards/pause-controls/screens-pause，60 用例），行为与拆分前逐字节等价（game-loop-integration 全链路回归锁定）。
- **M16 运行时修复与碰撞反馈**：热座 P2 回合渲染/HUD 数据源修复（frame-render/hud 按 hotseatPlayer 切 player2/tracks[1]，`frame()` 交棒后主动 `requestAnimationFrame(this.frame)` 重启 RAF——`shouldRender=false` 提前 return 曾导致 RAF 链断裂）；`collision-feedback.ts` 碰撞红闪纯函数（命中重置 + 指数衰减，常量 `COLLISION_FLASH_DURATION=0.35`/`COLLISION_FLASH_DECAY=6`/`COLLISION_FLASH_EPSILON=0.02`），`applyTrafficCollision` 返回 `{ hit, impact, cooldown }` + 横向弹开（贴车向远离侧推 0.12 防反复触发）；`shouldScheduleNextFrame(shouldRender)` 帧循环调度契约纯函数（false 停止 rAF 自续）；**2026-08-05 帧循环健壮性**：`loopRunning` 标记 + `ensureLoop()` 幂等重启（完赛后 RAF 链断，回菜单/再开赛/热座交棒时重启，防画面冻结）、`silenceDriveSounds`（离开 RACING 时静音引擎/漂移胎声/胎噪/雨声，防完赛/暂停后持续蜂鸣——完赛后 RAF 停摆 updateFrame 静音分支不再执行）；`RACE_START_GRACE` 起步保护期；`debug-hook` 加 `collisionFlash` getter。
- **M17 环境差异化**：`TrackDef.environment` 必选字段 + `engine/environment.ts` 环境配置唯一真源；渲染层按环境差异化光照色板、远山懒重建、景物形状（SpriteKind 扩展 cactus/palm/snowpile + rotation/scale）与地形装饰；`viewFor` 透传 `environment` 到 RenderView；game 层 `track-context` 用环境 profile 驱动景物生成、`refreshTrackPreview` 按环境取缩略图主题色、菜单背景按赛道 id 换 `track-xxx` 类。
- **M18 UI/UX 深度打磨（2026-08-05）**：本层虽以游戏逻辑为主，但为 UI/UX 提供运行级支撑：
  - **键盘可访问性**：`GameLoop.bindLeaderboardCards()` 绑定榜单卡片展开交互（click/Enter/Space 切换 `.expanded`，同步 `aria-expanded`），与 `buildTrackOptions` 的赛道按钮键盘导航共同构成菜单键盘可达路径。
  - **屏幕切换过渡**：`GameLoop.transitionScreenOut(screen)` 为目标屏幕加 `.leaving` 触发 CSS 退场淡出（150ms），`ui/screens.ts` 的 `setHidden` 识别 `.leaving` 跳过同步隐藏，待 `transitionend` 后再真正移除；暂停屏入场由 `.pause-in` 处理。
  - **触屏引导浮层**：`GameLoop` 在首次进入 `PHASE_RACING` 时显示 `#racing-touch-hint`（2s 淡出），文案取自 `ui/copy.ts` 的 `RACING_TOUCH_HINT`。
  - **BOOST 未蓄能反馈**：`GameLoop` 在键盘 Space/Enter 按下、P1 `boostCharge <= 0` 且未处于 boost 激活状态时，给 `#boost-bar` 加 `.no-charge` 红闪 300ms，防止玩家误以为按键无效。
  - **文案/空态同源**：榜单空态（`top-refresh.ts`）追加 `STATS_EMPTY_HINT`/`MATCH_EMPTY_HINT`，结算零漂移提示（`screens.ts`）追加 `FINISH_DRIFT_HINT`，全部来自 `ui/copy.ts` 唯一真源，避免硬编码中文。

## Flow

### 初始化（构造链）

`main.ts` 调 `initGame()` → `new GameLoop()` 构造：

1. **模式判定与 DOM 收集**：`?split` 与 `?hotseat`（`params.has('hotseat') && !splitMode`）解析模式，M12 加 `?challenge`（与双人模式互斥），M15 加 `?perf`（性能降级开关，与 split 不互斥）；`createModeStrategy` 按已解析标志创建策略实例；`$()` 帮助函数取全部 HUD/屏幕元素，DOM 组装下沉 `dom-setup.ts`（`collectHudElements`/`collectScreenElements`）；`#menu-hint` 文案取 `mode.menuHint`；模式徽章 `#menu-mode-badge`（分屏/热座/挑战显式标识，单屏隐藏）；分屏为 body 加 `split-mode` 类并显示 `hud2`（2026-08-06：`p2-track-name` 赛道名元素已随菜单专项优化移除）；读取持久化音量（`loadVolumeFromStorage`/`loadMusicVolumeFromStorage`/`loadSfxVolumeFromStorage`）。
2. **暂停控件与赛道选项**：`bindPauseControls()` 绑定三个音量 slider + 重开/继续/触屏暂停/结算返回按钮；`buildTrackOptions` 按 `TRACK_DEFS.length`（9）动态构建赛道按钮（文本 `${i + 1} ${def.name} ${'★'.repeat(difficulty)}${'☆'.repeat(3 - difficulty)}`，E5 星级 + diff-1/2/3 颜色编码 + title 难度提示），按钮 click/keydown(Enter/Space) 等价键盘 1-9；`refreshTrackPreview(0)` 渲染中央赛道缩略图 SVG。
3. **TrackManager**：注入 `{ resetRace: () => this.resetRace(), trackName, p2TrackName, splitMode, trackOptions }`，内部用 `TRACK_DEFS[0]` 创建双上下文并刷新选单高亮。
4. **基础件**：`createCarConfig()`、`createRaceState()`（双 PlayerState + 双 `TrackContext(TRACK_DEFS[0])` + `lastLap/lastLap2` 初始 1 + `phase: PHASE_MENU`）。
5. **Renderer**：以 `trackManager.getContext(0)` 的 segments/roadside sprites/traffic 创建；`syncRendererTrack(0)` 立即预热道路段离屏缓存（须以 race.tracks 为准才能命中 useCache 判定）；`createInputManager(window)` 注册键盘监听；`JoystickUI().attach(canvas)`；`updateJoystickVisibility(false)` 菜单阶段隐藏摇杆。
6. **存档与调试钩子**：`loadBestTime(getTrackId(0))` / `loadBestTimeFor(1, getTrackId(1))`；`updateTrackBackground(0)` 菜单背景赛道主题类；`installDebugSinks()` 暴露 32 个 getter（含 M28 guideStrength/routeChoosing/dailyState 等，见 debug-hook 条目）。
7. **启动**：注册 `keydown`/`resize` 监听（及 `#start-btn` 开始按钮 click、榜单卡片展开交互 `bindLeaderboardCards`），调用 `refreshDriftTop()` + `refreshBestSummary()` + `refreshMatchTop()`，`ensureLoop()` 首次调度 `requestAnimationFrame(frame)`。

### 每帧（frame）

**M15 起 frame 为薄壳**：`dt = min((now - last) / 1000, 0.05)` 截断防跳帧 → `updateFrame(dt, ctx)`（更新段全部下沉，返回 `shouldRender=false` 时跳过渲染）→ 写回帧间状态（lastActivePlayer/boostActive/lastCollisionCount/collisionFlash/challengeTimer/challengeScore/boostBar）→ `shouldScheduleNextFrame(ur.shouldRender)` 判定（false 时置 `loopRunning = false` 并 return——完赛/挑战限时触发 finish 等价旧帧内 return）→ 计算 steer1/steer2（`mode-strategy.collectSteerInputs` 纯函数，与 updateFrame 内 `mode.getInputs` 路由完全同源，保证渲染倾斜与物理转向输入源一致）→ `renderFrame(dt, ctx)`（渲染段三分支）→ 写回小地图引用 → `engineSound.setSpeedRatio`（仅 RACING）→ `requestAnimationFrame(frame)` 自续。下述 1-3 步骤即 updateFrame/renderFrame 内部的实际内容：

1. **PHASE_RACING 更新段**（frame-update.ts，非 RACING 分支静音漂移胎声/胎噪后直接返回）：
   - 雨段环境音与雨天物理：`raining = Math.floor(player1.raceTime / WEATHER_CYCLE_SECONDS) % 3 === 2` → `rainSound.start()/stop()`，`wet = raining`，`challengeMult`（仅 challengeMode：`1 + (raining ? 0.5 : 0) + (difficulty - 1) * 0.25`）。
   - 挑战倒计时/实时得分 HUD：惰性获取 `#challenge-timer`（`剩余 X.Xs`，≤10s `.urgent`）与 `#challenge-score`（`得分 N`），仅挑战模式。
   - 双世界车流推进：`updateTraffic(tracks[0].traffic, dt, lapLength, { z: player1.cameraZ, x: player1.carState.position })`（P4 传玩家位置启用车流避让）；`mode.shouldUpdateP2Traffic(hotseatPlayer)` 时再推进 `tracks[1]`（分屏恒 true / 热座仅 P2 回合 / 单屏挑战 false）。
   - 输入获取与路由：`mode.getInputs({ joystickActive, joystickInput, p1Input, p2Input })`——单屏/热座/挑战合并双键盘（mergeCarInputs）且 input2 零输入、分屏独立；摇杆 active 优先。`mode.updateActivePlayer` 分屏按输入更新最近活跃玩家（P1 优先）。
   - **BOOST 蓄力/消耗（M12 G4）**：P1/P2 各调 `updateBoostCharge(boostCharge, dt, input.boost === true, driftState.active)` → 回写 `boostCharge`，`effInput = { ...input, boost }`；`#boost-bar` 惰性获取设宽度 `Math.round(charge × 200)px`。**M18 未蓄能反馈**：键盘 Space/Enter 按下且 `boostCharge <= 0`、未处于 boost 激活状态时，给 `#boost-bar` 加 `.no-charge` 红闪 300ms。
   - **H2 BOOST 音效/粒子**：`boostOn = effInput1.boost || effInput2.boost`，`boostOn && !boostActive` 边沿 → `boostSound.play()`，回写 `boostActive`；P1 激活期间每帧至多 push 1 粒 `BoostParticle { x: position, z: cameraZ + 2, t: 0 }`，倒序遍历 `t += dt`、超 0.6s splice 移除。
   - 玩家物理更新（`mode.updatePlayers`）：非热座 P1/P2 各一次（`updateBothPlayers`，P1 传 `lapTimes`、P2 传 `lapTimes2`），**H5 直返赋值** `race.lastLap = updatePlayerFrame(...)`；热座仅当前回合玩家（`updateCurrentHotseatPlayer`，共用 input1）。
   - 碰撞：`updateCollisions(race, dt, mode.collisionIncludesP2(hotseatPlayer), maxSpeed)`——P1 恒检测（raceTime ≥ RACE_START_GRACE 时），P2 分屏恒/热座仅 P2 回合；返回 `{ hit, impact }` → `updateCollisionFlash(ctx.collisionFlash, hit ? flashSeedFromSpeedRatio(impact) : null, dt)` 写回红闪；`collisionCount > lastCollisionCount` → `collisionSound.play(impact)`（H6 强度）并同步快照。
   - 漂移胎声/胎噪（M15）：`driftActive` 时 `driftSound.start()` + `setIntensity(速度比, 转向绝对值, wet)`，否则 `stop()`；`tireSound.setLevel(P1 速度比, |steer1|, wet)` 常驻低音量。
   - 完赛判定：`mode.shouldFinish(race, trackManager, hotseatPlayer)`（挑战限时优先 + 正常圈数判定）→ 命中调 `ctx.onFinish()`（= `applyPhase(PHASE_FINISHED)`）并返回 `shouldRender=false`。
2. **渲染三分支**（frame-render.ts，每帧必然执行其一）：
   - `PHASE_MENU`：双预览相机按各自圈长推进（`advancePreviewCameraZ`，`PREVIEW_CAMERA_SPEED=500`），`setCameraX(sin(z*0.001)*0.3)` 横向摆动；分屏时 `renderRegion` 左右各渲染各自世界 + `drawDivider(w/2)`，单屏时 `render` P1 世界预览（预览不传 boostParticles）。
   - 分屏比赛：`setCameraX(player.carState.position)` + `renderRegion`（各自 cameraZ/smoke/raceTime/view + `boostParticles` + speedRatio/boosting/steer/collisionFlash）+ `drawDivider(w/2)`。
   - 单屏比赛：`setCameraX` + `render`；**热座 P2 回合按当前回合玩家切换数据源**（player2/tracks[1]/p2SpeedRatio——否则画面冻结在 P1 完赛瞬间）。
   - 收尾：小地图（RACING 且非分屏时惰性创建 `Minimap`，`trackContext` 变化重建，热座 P2 回合跟随当前回合玩家，更新后按 `showMinimap` 显隐）；`updateHud(hudElements, race, carConfig, bestTime, splitMode, race.tracks, phase, bestTime2, hotseatMode ? hotseatPlayer : null)`。
3. **收尾**：`engineSound.setSpeedRatio(speed / maxSpeed)`（仅 RACING）；**M18 触屏引导**：`PHASE_RACING` 首次进入时显示 `#racing-touch-hint` 浮层（文案 `RACING_TOUCH_HINT`），CSS 控制 2s 淡出；`requestAnimationFrame(frame)` 自续（完赛路径由 ensureLoop 兜底重启）。

### 关键调用链

- **`resetRace()`**（菜单进入前 / 换赛道后 / 热座交棒）：`resetRaceState(race)`（清双玩家状态与计数，保留 `phase`、不重建 `tracks`）→ `refreshTraffic(tracks[0])` + `refreshTraffic(tracks[1])`（引用替换重建车流，带出生安全窗口）→ `last = performance.now()` + `lastCollisionCount = 0` 快照同步 → 重载双最佳圈速。
- **`applyPhase(newPhase)`**：写入 `this.phase` → 非 RACING 时 `silenceDriveSounds(newPhase !== PHASE_PAUSED)`（引擎/胎噪/漂移静音，暂停保留雨声）→ **M18 屏幕过渡**：调用 `transitionScreenOut(startScreen/finishScreen/pauseScreen)` 为离开的屏幕加 `.leaving` 触发 CSS 淡出，由 `ui/screens.ts` 的 `setHidden` 识别 `.leaving` 避免同步冲突 → MENU/RACING 时 `ensureLoop()` 重启帧循环 → `PHASE_PAUSED` 时 `joystick.reset()` + 暂停标题动态标注 → `pauseBtn.hidden = newPhase !== PHASE_RACING`（挑战倒计时/实时得分/小地图兜底显隐）→ **M15 起**调 `accountFinish({ race, trackManager, mode, hotseatPlayer, prevP1Time, record })`（`finish-accounting.ts` 纯函数，`record` = `PHASE_FINISHED && !finishShown` 防 ESC 重入；返回 `{ finishedP1, finishedP2, driftWinner, winStats }`——完赛标记按各玩家本世界圈长/总圈数恒计算、漂移获胜者仅分屏双完赛按 `Math.round(score)` 比较平局归 P1、记账部分热座 round 2 按 `prevP1Time` 与 P2 用时比较得胜者（平手 null）/分屏双完赛复用 `driftWinner` 且非 null 时 `recordWin(hotseat|split, winner)`、各完赛玩家漂移正分 `addDriftScore({ player, trackId, score, time, combo })`（P1 条件放宽 `finishedP1 || challengeMode`）、分屏双完赛 `addMatchResult` 记对局榜）→ 首次完赛时 `refreshDriftTop()` + `refreshMatchTop()` → `applyPhaseToScreens(screenElements, newPhase, race, carConfig, { splitMode, finishedP1, finishedP2, hotseatMode, hotseatRound, prevP1Time, driftWinner, winStats, challengeMode })`（9 字段 opts，屏幕显隐/结算由 ui/screens 负责）→ `PHASE_FINISHED` 时重载双最佳圈速；`PHASE_MENU` 时 `resetRace()` + `updateJoystickVisibility(false)` + `refreshDriftTop()` + `refreshBestSummary()` + `refreshMatchTop()`。
- **`selectTrackFor(playerIndex, trackIndex)`**（菜单数字键/方向键/按钮触发）：`trackManager.selectTrack(playerIndex, trackIndex)`（重建该玩家上下文 + 内部触发 `resetRace` 回调 + 刷新选单高亮）→ `race.tracks[playerIndex] = trackManager.getContext(playerIndex)`（双引用同步）→ `previewCameraZ[playerIndex] = initialPreviewCameraZ(trackIndex, lapLength)`（按圈长 1/N 等分重置预览起点，N = `TRACK_DEFS.length`）→ P1 时 `refreshTrackPreview` + `updateTrackBackground` → `syncRendererTrack(playerIndex)`（重建道路段离屏缓存）。热座 P1 选赛道后 `mode.afterSelectP1Track` 同步 P2 世界（`selectTrack(1, ...)` + `race.tracks[1]` + `previewCameraZ[1]`），保证双人同赛道。
- **`onKeyDown`**：`Escape` → `applyPhase(togglePause(phase))`；`PHASE_PAUSED` + `KeyR` → 回菜单；`PHASE_MENU` 方向键 3x3 网格导航（`ArrowLeft/Right/Up/Down`，焦点跟随）；`PHASE_MENU` + `Digit`：分屏 `Shift+1-9` 选 P2 赛道（无效数字也在此分支吞掉），`1-9` 选 P1 赛道 + `afterSelectP1Track`；菜单修饰键单独按下（8 个 code）不触发开始；**热座交棒**：`PHASE_FINISHED` + hotseatMode + (`Enter`|`KeyR`) + `hotseatPlayer === 1` 时 `prevP1Time ??= player1.raceTime` → `hotseatPlayer = 2` → `resetRace()` → `race.phase = PHASE_RACING` → `applyPhase(PHASE_RACING)`（绕过 `nextPhase`，resetRaceState 已重置 finishShown=false 保证 P2 回合结算可再次填充；applyPhase 内 ensureLoop 重启 RAF）；菜单阶段仅空格/回车开始；其余阶段任意键 `startGame()`。
- **`startGame()`**：首次调用时 `createAudioRig(new AudioContext(), volume, musicVolume, sfxVolume)` 惰性装配全部音频（满足浏览器自动播放策略）并写入各字段 → `updateJoystickVisibility(true)` → `PHASE_MENU` 时 `startCountdown()`（runCountdown 3→2→1→GO；**2026-08-08 触屏适配：按 `detectTouchPrimaryInput()` + `mode.splitMode` 选择提示文案——键盘 `COUNTDOWN_HINTS` / 单屏触屏 `COUNTDOWN_HINTS_TOUCH` / 分屏触屏 `COUNTDOWN_HINTS_TOUCH_SPLIT`**）→ `applyPhase(nextPhase(phase, lapFromZ(...), totalLaps))`（menu→racing，超圈 → finished，finished→menu）。
