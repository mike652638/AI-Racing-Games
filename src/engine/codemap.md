# src/engine/

## Responsibility

该目录是游戏的**伪 3D 渲染引擎层**（Canvas 2D，非 WebGL）。职责包括：

- **投影数学**：提供相机模型与透视投影纯函数（`project`），将世界坐标（地面平面 y=0，相机朝 +z）映射为屏幕坐标与缩放；相机后方/平齐的点返回 null。
- **赛道定义与生成**：定义分段路点数据结构（`Segment`）与生成器（分组曲线 `createTrack` / 控制点平滑插值 `createSmoothTrack`），提供环形 O(1) 分段定位（`trackIndexForCameraZ`）与总曲率统计（`totalCurve`）；`tracks.ts` 维护赛道定义注册表（`TrackDef` / `TRACK_DEFS`，M9 起 9 条赛道且 `TrackDef.difficulty: 1|2|3` 星级必选，`TrackDef.trafficCount?` 可覆盖默认车流密度，M11 起可选 `TrackDef.timeOfDay?: 'day' | 'night'` 夜晚赛道标记——canyon 峡谷疾驰与 alpine 山岳险道设 `'night'`，缺省视为白天，M17 起必填 `TrackDef.environment` 环境场景）。
- **路面几何**：分段四边形的投影（`projectSegmentQuad`）、路面/路缘按段号奇偶配色（M16 起路面交替色收敛为 `#484848/#404040` 亮度差 8，缓解远端密集条纹）、中心线虚线绘制判定。
- **环境配置（M17 新增）**：`environment.ts` 为 9 种环境（plains/highway/s-curve/island/canyon/desert/forest/coast/alpine）提供单一真源配置——天空/草地色相、远山 day/night 双配色、景物类型与密度、树木配色、菜单缩略图主题色、地形装饰（dunes/sea/rock）、**M18 环境车灯配色**（`headlightColor?: string`——canyon 红棕暖光 `#ff8a5c` / alpine 冷白 `#dff1ff`，其余不设缺省玩家车默认黄白）。
- **景物系统**：确定性 PRNG（`mulberry32`）、视差远山轮廓生成；路边树/路灯/仙人掌/棕榈/雪堆的确定性成对生成（M17 SpriteKind 扩展 + rotation/scale 随机化）、环形可见窗口查询（`spritesInRangeIndexed`，段分组索引 O(候选段数)）、曲率前缀和（O(1) 累计偏移）。
- **车流系统**：确定性车流生成/推进/玩家碰撞（数据层，P4 起玩家逼近时避让变道 AI，2026-08-05 起避让后可渐变恢复巡航偏移），以及车流投影渲染（过滤 + 远→近排序 + 近距高度 clamp）。
- **漂移烟雾渲染**：烟雾粒子投影（近大远小、透明度随存活衰减）。
- **环境光照**：昼夜循环配色（120s 周期四段 HSL 插值）+ 天气循环（晴/阴/雨三态各 45s 循环，`WEATHER_CYCLE_SECONDS`，阴/雨天整体降饱和压暗）+ 赛道级夜晚模式（M11：night 锁定深暗蓝紫/暗绿色板，不随时段插值）+ M17 第 5 参 `environment`（按环境差异化天空/草地色相，night 草地色相亦按环境微调）。
- **渲染门面**：`Renderer` 类组合全部子模块，对外暴露 `render`（M14 起尾参 `renderOpts?: RenderOptions` 渲染降级）/ `renderRegion`（分屏）/ `drawDivider`（分屏分隔线）/ `setViewport` / `setTrack` / `setTraffic` / `setCameraX`；`RenderView` 提供多视图参数化渲染（分屏双世界各持一份，避免每帧重建）；M17 起远山离屏缓存按环境懒重建；H2 起支持 BOOST 尾焰粒子投影（`BoostParticle` 纯数据接口，game 层维护生命周期、渲染层投影绘制）；M16 起碰撞红闪（`collisionFlash` 视图字段 → `drawCollisionVignette`），M18 起同字段同时驱动玩家车碰撞边框闪白（`drawPlayerCar` flash 白→红插值描边）。

## Design

- **纯函数分层**：`projection.ts`、`road-geometry.ts`、`sprites.ts`、`scenery.ts`、`traffic.ts`、`traffic-render.ts`、`smoke-render.ts`、`lighting.ts`、`track.ts`、`tracks.ts`、`road-strip.ts`、`environment.ts` 均为无副作用纯函数/数据模块（输入世界坐标/时间/种子，输出投影或颜色或数据），不接触 DOM，易于单测；2026-08-05 拆分的 `sprite-draw.ts` / `screen-effects.ts` / `traffic-draw.ts` / `terrain-draw.ts` / `road-surface.ts` 亦为 ctx 显式传入的纯函数绘制模块（不持有 canvas 状态）；仅 `renderer.ts`（`Renderer` 类持有 ctx）与 `player-car.ts`（`drawPlayerCar` 玩家车绘制）直接触达 Canvas 2D 实例状态。
- **门面模式（Facade）**：`renderer.ts` 的 `Renderer` 类组合所有子模块，对外只暴露 `render` / `renderRegion` / `drawDivider` / `setViewport` / `setTrack` / `setTraffic` / `setCameraX` 等粗粒度 API；`src/game/game-loop.ts` 仅依赖 `Renderer` 与少量数据生成函数。2026-08-05 拆分瘦身（1143→约 611 行，M18 再增）：景物形状 / 屏幕特效 / 车流 / 地形装饰 / 道路渲染下沉至 `sprite-draw.ts` / `screen-effects.ts` / `traffic-draw.ts` / `terrain-draw.ts` / `road-surface.ts` 五个纯函数模块（Renderer 仅保留生命周期、入口渲染、远山/雨/道路段缓存与粒子投影调度）。
- **RenderView 视图参数化**：`render(cameraZ, smoke?, timeSec?, view?, renderOpts?)` 与 `renderRegion(cameraZ, viewX, viewW, smoke?, timeSec?, view?, renderOpts?)` 的尾参 `view?: RenderView`（`track` / `curvePrefixSum` / `spriteIndex` / `traffic` 四件套 + M11 可选 `night?: boolean` 夜晚赛道标记 + M17 可选 `environment?: LightingEnvironment` 环境 + H2 可选 `boostParticles?: BoostParticle[]` BOOST 尾焰粒子 + M8 可选 `speedRatio` / `boosting` + M16 可选 `collisionFlash` 碰撞红闪 + H2 可选 `steer` 实时转向输入）——分屏 P1/P2 各传自己的 `TrackContext` 视图，单次渲染零重建（预计算在 `createTrackContext` 时完成）；缺省时在 `renderWithOpts` 内部回退构造为 Renderer 自身字段（`setTrack` / `setTraffic` 设置的默认视图）。实施注记：原案 `view ?? this` 因 `track` / `curvePrefixSum` 等为 private 字段无法做结构兼容赋值，改为类内显式对象构造（语义一致，见计划 Task B2 实施偏差）。
- **RenderOptions 渲染降级（Task 9）**：`render` / `renderRegion` 尾参 `renderOpts?: RenderOptions`——`drawDistance` 覆盖默认 `DRAW_DISTANCE`(120)、`skipSmoke` / `skipBoostParticles` / `skipRain` / `skipPlayerCar` 跳过对应特效层（菜单预览等降级场景用）；所有字段可选，缺省（undefined）时与既有渲染行为完全一致（零回归）。
- **renderRegion 分屏裁剪 + 整数像素对齐**：`renderRegion` 先按 `buildOpts(viewW, height)` 重建投影参数，`Math.round(viewX)` / `Math.round(viewW)` 做整数像素对齐（窗口宽为奇数时 w/2 是 x.5，半像素 translate/clip 会导致交界处 1px 级重叠/缝隙、近处路缘石斜边交错成"三角形重叠/撕裂"），再 `ctx.save / translate / clip` 限定绘制区域，`restore` 复位。
- **drawDivider 分屏分隔线**：全高 4px 深色渐变竖线（中心 `rgba(0,0,0,0.65)`、两侧透明，视觉不生硬），覆盖两区域近处路缘石交错瑕疵；必须在 `renderRegion` 的 `ctx.restore()` 之后调用（transform 已复位，用全屏坐标，x 以全屏原点计）。
- **环形赛道曲率前缀和**：`buildCurvePrefixSum` 预计算 `Float64Array`（`prefix[i+1] = prefix[i] + track[i].curve`），`curveOffsetAtZ` 以 `trackIndexForCameraZ` 定位段 + 段内线性插值实现 O(1) 累计中心线偏移查询；路面分段绘制时另以 `curveSum` 逐段累加。
- **buildSpriteIndex 空间索引**：景物按 `floor(z / SEGMENT_LENGTH)` 分组为 `Map<number, Sprite[]>`；`spritesInRangeIndexed` 仅遍历相机前方 `floor(viewDistance / SEGMENT_LENGTH) + 2` 个候选段（不超过总段数，视距 ≥ 环长时退化全环），逐精灵过滤语义与线性版一致（环形回绕 + 绝对 z 化 + relZ ≤ viewDistance；线性版 `spritesInRange` 已随死代码清理迁移至 `tests/helpers/sprites.ts`，仅供测试作基准对照）；重载支持传 `out` 复用数组（每帧清空重填并返回匹配数量，避免帧内新建数组，Task B-5）。
- **M14 曲率段（road-strip）预计算**：`road-strip.ts` 的 `buildRoadStrips` 按曲率差阈值（`curveThreshold=0.001`）+ 段数上下限（min 20 / max 50，段数不足 min 时不按曲率差拆分）把赛道分段合并为 `RoadStrip { startSeg, endSeg, startZ, endZ, curveAvg }`；`renderRoadStripToCanvas` 将单个 strip 预渲染到离屏 canvas（路肩/路面/中心虚线烘焙进纹理，M16 起路面 9 带横向渐变 `ROAD_LIGHTNESS_FACTORS` + 确定性颗粒噪点 `ROAD_NOISE_PER_SEG=14`）；`game/track-context.ts` 的 `createTrackContext` 预计算 `roadStrips` 供渲染层切片 drawImage 加速（Task A 已激活消费路径，Renderer.setTrack 预热 `roadStripCache` + `stripForSegment` 映射）。
- **确定性生成**：`scenery.ts` 的 `mulberry32` PRNG 是唯一随机源；远山轮廓（种子 2024 / 77）、路边景物（seed=1234，间距由环境配置驱动，default 800，树/灯比例由环境 treeRatio 驱动）、车流（seed=777，createTraffic 函数默认 8 辆；赛道层经 `def.trafficCount ?? TRAFFIC_DEFAULT_COUNT`（真源 src/shared，classic 缺省 14、highway 16 等，见 tracks.ts）生效；M16 起出生安全窗口 `TRAFFIC_SPAWN_SAFE_ZONE=1600` 防开局碰撞）、雨滴（seed=2026，80 条，renderer 构造时生成）均由种子生成，结果可复现（利于 bot 校验与存档）。
- **离屏缓存**：远山两层轮廓先经 `renderMountainOffscreen` 渲染为 offscreen canvas（首尾闭环：右端点强制与左端点等高，消除双幅平铺接缝垂直台阶，P3 天空条纹），再按 `parallaxOffset` 视差偏移平铺 `drawImage`（双份平铺覆盖滚动窗口），避免每帧重绘路径；M17 起按环境懒重建——`renderWithOpts` 每帧比对 `view?.environment ?? 'plains'` 与 `currentEnv`，不一致时按 `getEnvironmentProfile` 的 far/near（含 day/night 两套）重建离屏位图（切换赛道重建一次，运行时零成本）。
- **天气循环（晴/阴/雨三态，P5）**：`renderWithOpts` 以 `phase = Math.floor(timeSec / WEATHER_CYCLE_SECONDS) % 3` 判定天气（0 晴 / 1 阴 / 2 雨，各 45s 循环）并传入 `updateLighting(timeSec, overcast, raining, night, environment)`（`overcast = phase === 1`、`raining = phase === 2`、`night = view?.night ?? false`）；阴/雨天时所有 HSL 输出经 `overcastHsl` 降饱和（s×0.4）压暗（l×0.8，色相不变，四舍五入取整；雨天复用阴天配色仅语义区分），4 段昼夜插值逻辑共用同一配色管线，晴天输出与旧版逐字节一致。
- **夜晚模式（赛道级，M11 F1）**：`updateLighting` 第 4 参 `night` 为 true 时在昼夜插值前锁定深暗色板——`skyTop hsl(220,55%,12%)`/`skyBottom hsl(210,50%,8%)`/`mountainFar hsl(220,30%,10%)`/`mountainNear hsl(220,35%,8%)`（不随 timeSec 时段变化，天空/远山夜间统一；night=false 输出逐字节不变），M17 起草地色相按环境微调 `grass hsl(env.grassHue,30,12)`（plains 130 / canyon 25 红棕 / alpine 60 冷灰）；`Renderer` 构造/`setViewport` 时按 `buildMountains(width, colorFar, colorNear)` 参数化构建 day/night 两套远山离屏缓存（`mountains` 默认 `#27425e`/`#1f3046`、`mountainsNight` 深色 `#101a2a`/`#0a1220`），`renderWithOpts` 按 `view?.night` 选择（分屏 P1 day + P2 night 双世界正确）；night 时每辆可见车先画红色尾灯双灯（`#ff3b30`：`cx ± width*0.3`、宽 `width*0.2`、从 `top.y + height*0.7` 起高 `height*0.25`，车头朝画面上方故尾灯在车身下部），再经 `traffic-draw.ts` 的 `drawHeadlight` 画车头双弧光晕（外层 `rgba(255,235,180,0.35)` 半径 ×1.6 + 核心 `#ffe08a`，中心在车身上部、半径随 scale），night=false 零新增绘制；**M12 G2 车灯随变道转向**——`drawHeadlight(ctx, cx, topY, width, height, steerDir)` 第 5 参 `steerDir: -1|0|1` 取 `car.car.shiftDir`（投影对象嵌套原始车数据），核心灯 `cx + steerDir*width*0.35`、外层光晕 `cx + steerDir*width*0.18`（光晕扩散方向与核心一致、幅度更小；steerDir=0 与旧版逐字节一致）。
- **车流避让 AI（P4）**：`updateTraffic` 可选尾参 `player?: { z: number; x: number }`——车在玩家前方环形距离 `d = (car.z - player.z + lapLength) % lapLength ∈ (0, 350)` 且 `|car.offset - player.x| < 1.2`（同/近车道）时，向远离玩家的一侧渐变变道（步进 `AVOID_STEP = 0.8`/s、clamp `|offset| ≤ 0.85`）；d === 0 或车在玩家后方（d 接近 lapLength）天然不触发。**2026-08-05 起变道可恢复**：触发条件消失后以同样步进渐变恢复回 `cruiseOffset`（createTraffic 初始 = 出生偏移；手工构造未赋值时目标即当前 offset，不产生恢复位移）；`TrafficCar` 加必填 `shiftDir: -1 | 0 | 1`（createTraffic 初始化 0；避让分支 `shiftDir = player.x > 0 ? -1 : 1`、恢复途中指示恢复方向、到达巡航偏移时归零），渲染层车灯随其转向。不传 player 时行为与旧版完全一致（既有调用零改动）。
- **雨滴 overlay + 离屏缓存（P5 / M11 F5）**：`renderWithOpts` 末尾（烟雾/尾焰层之后、最上层特效，忽略投影）`if (raining && !renderOpts?.skipRain) this.drawRain(timeSec, opts)`——`RAIN_DROPS = 80` 条雨丝由 `mulberry32(2026)` 在构造时确定性生成（`RainDrop { x, y0, len }`，x 为宽度归一化 0-1 乘当前宽度，`setViewport` 改尺寸不重算）；F5 起雨丝预渲染到离屏 `rainCanvas`（`buildRainCanvas(opts)`：宽 = opts.width、高 = opts.height + 20，B7 起雨丝固定 15° 倾斜（风向感，预计算 sin/cos），长度 12-24，`strokeStyle = 'rgba(180, 200, 220, 0.5)'`、`lineWidth = 1` 一次性 stroke；构造器与 `setViewport` 均重建），帧内 `drawRain` 改为双幅 `drawImage(rainCanvas, 0, yOffset - h)` + `drawImage(rainCanvas, 0, yOffset)`（`yOffset = ((timeSec * 600) % h) - 10`，h = opts.height + 20，600px/s 下落环形回绕无缝、保留 -10 上移视觉语义），替代原每帧 80 段线段逐段绘制（性能优化）。
- **BOOST 尾焰粒子（H2）**：`BoostParticle` 接口定义于 `renderer.ts`（纯数据 `{ x, z, t }`——x 横向偏移 / z 世界位置 / t 存活时间；与渲染相关故定义于此，game 层维护、audio 层不依赖）；`RenderView` 可选 `boostParticles?: BoostParticle[]`（缺省无粒子，菜单预览不传）；`renderWithOpts` 在烟雾层之后、玩家车/雨层之前 `if (!renderOpts?.skipBoostParticles && v.boostParticles?.length)` 逐粒投影（仿 smoke）：`project` 求屏幕位置、半径 `max(scale * opts.height * 0.15, 2)`、透明度随存活衰减 `max(1 - t / 0.6, 0)`、填充 `rgba(255, 180, 80, alpha)` 橙色圆、圆心在 `proj.y - radius * 0.5`（车身后上方）；game 层（`game-loop.ts`）P1 boost 激活期间每帧至多 push 1 粒（`z = cameraZ + 2` 保证投影非 null），帧末推进 t、超 0.6s 移除。
- **景物 + 车流合并景深绘制（2026-08-05 z-order 修复）**：`drawWorldObjects` 将两类世界物体各自投影后按 z 降序双指针归并绘制（画家算法）——旧版先画全部景物再画全部车流，远处车永远覆盖近处树/路灯（不合常理）；景物中心减去相机自身曲率偏移（`curveOffsetAtZ` 返回赛道绝对前缀和，路面渲染的曲率累计以相机为起点归零，不减相机偏移会在弯道上系统性漂移，实测最大 0.36 世界单位）；`spriteScratch` 复用数组避免帧内新建。
- **距离大气透视（2026-08-05 道路平滑化）**：`road-surface.ts` 导出 `drawDistanceFog(ctx, opts, skyBottom, fogBandRatio = 0.42)`——地平线向下的一段垂直渐变雾霾层（远端路面/景物/车流渐融入天空雾色），消除远端分段压缩形成的密集条纹（摩尔纹）与"远端对比度与近处一致"的平板感；画在世界物体之上、烟雾/玩家车之下（近处不受影响），纯函数帧内一次渐变填充。
- **M18 引擎渲染细节打磨**：①**碰撞车身边框闪白落地**（M16 设计意图）——`PlayerCarOptions.flash?: number`（0-1，collision-feedback 状态驱动，renderer 传 `view.collisionFlash`）在 `drawPlayerCar` 车身外描边（`rect`+`stroke`，色随强度白→红插值 `FLASH_WHITE_RGB`/`FLASH_RED_RGB`、线宽 `FLASH_LINE_WIDTH = 3`、随转向倾斜变换）；②**精灵近距缩放上限**——`projection.ts` 导出 `MAX_SPRITE_SCALE = 2.2` 常量与 `clampSpriteScale(scale)` 函数，clamp 放精灵侧（`drawSpriteProjected` 消费），`project` 因与路面 quad 投影共用保持原语义（不内部 clamp）；车流侧保留既有 `MAX_TRAFFIC_HEIGHT_PX` 保宽高比 clamp，不叠加 `clampSpriteScale`（双重 clamp 会破坏宽高比契约，traffic-render.ts 注释固化取舍）；③**环境车灯配色**——`EnvironmentProfile.headlightColor?: string`（canyon `#ff8a5c` 红棕暖光 / alpine `#dff1ff` 冷白），renderer 每帧经 `getEnvironmentProfile(environment)` 传入 `drawPlayerCar` 覆盖默认核心灯色 `#ffe08a`（night 赛道可见，day 低可见度无副作用）；④**路缘柔和过渡**——`road-surface.ts` 新增内部 `drawCurbDetail`/`drawCurbSide`（`CURB_*` 常量）：内侧 2px 暗色分隔线 `shadeColor(路缘色, 0.75)`（阴影）+ 外侧 2px 高光条 `shadeColor(路缘色, 1.15)`（高光），屏幕空间近/远缘独立插值细分、路缘屏幕宽 <6px 自动跳过（远端压缩段不可见 + 控制每帧成本），缓存切片与逐段回退两条路径共享（叠加在道路层之上，不改纹理烘焙布局）；⑤**地形细节三件套**——沙丘 sin 变形（`DUNE_STEPS = 12` 折线逼近、`DUNE_WAVES`/`DUNE_WAVE_AMP`/`DUNE_PHASES` 预计算相位常量、端点包络归零附着地面、帧内零新建数组）、仙人掌按投影 scale 远近两档明暗（<0.35 时 `shadeColor(treeColor, 0.8)` 偏暗冷降饱和、近档原色）、海面波浪 y 随 `time` 轻微漂移（`WAVE_DRIFT_*` 常量，`drawTerrain` 新增可选第 5 参 `time = 0` 向后兼容，renderer 传累计 timeSec）。
- **白天天空恒蓝（M9 绿天空修复）**：M8 时代白天段 skyTop 色相从蓝 210 线性插值到橙黄 25，中途经过 hue≈117 绿色导致正午天空变绿（阴天降饱和后为绿灰）。M9 修复：白天段（phase 0.25-0.5）`skyTop` 色相恒 210 / `skyBottom` 恒 200（仅明度随 t 变化）；黄昏段（phase 0.5-0.75）`skyTop` 从 210 过渡到 220（蓝→紫，不再经过绿/橙黄）；黎明段（210/200 恒蓝）与夜晚段（220→210）不变。M17 起白天/黄昏/黎明的色相锚点改为环境 skyHue（plains 逐字节不变，desert 暖橙天空、coast 更蓝等）。「亮青竖条纹」经浏览器实测确认为山脊谷底透出天空的正常山形剪影（非渲染伪影），无需修渲染。
- **画家算法分层**：渲染顺序固定为 天空渐变 → 远山（视差平铺）→ 草地 → 地形装饰（M17）→ 路面分段（缓存切片/逐段回退，远→近）→ 景物+车流（远→近交错归并）→ 距离雾 → 烟雾 → BOOST 尾焰 → 玩家车 → 雨 → 速度线/BOOST 金色 vignette/碰撞红色 vignette，靠绘制顺序保证遮挡正确。
- **玩家车精灵（P0 / UX-9 / M18）**：`player-car.ts` 的 `drawPlayerCar` 为屏幕底部固定精灵（不参与世界投影）：随 `laneOffset` 横向平移（`laneOffsetToPx` clamp 画面内）、按 `steer` 实时输入 ±5° 倾斜（save/rotate/restore）、夜间车头双灯 + 光晕（UX-9：光晕 alpha 0.35→0.25、半径倍率 1.6→1.25，防大团光晕笼罩车体）+ lighter 合成光柱 + BOOST 车尾尾焰；M18 起支持碰撞边框闪白（`flash` 白→红插值描边，M16 设计意图落地）与环境车灯配色（`headlightColor`，night 赛道按环境传入）；由 renderer 在雨层之前每帧调用（`skipPlayerCar` 可降级）。
- **常量真源集中**：渲染与车流常量真源在 `src/shared/constants.ts`（2026-08-05 解环 game↔ui 后由 game/constants 提升至共享层；`RENDER_DRAW_DISTANCE = 120`、`RENDER_HORIZON_RATIO = 0.35`、`RENDER_DEPTH_RATIO = 0.84`、`ROAD_HALF_WIDTH = 1`、`EDGE_WIDTH = 0.15`、`TRAFFIC_DEFAULT_COUNT = 14`）；`renderer.ts` / `road-geometry.ts` / `road-strip.ts` 直接导入 src/shared；`road-geometry.ts` re-export `EDGE_WIDTH` / `ROAD_HALF_WIDTH` 并提供兼容导出 `DRAW_DISTANCE`（= `RENDER_DRAW_DISTANCE`，消费方建议迁移至常量），`renderer.ts` 再 re-export 三者供外部统一引用；`src/game/constants.ts` 为 re-export 兼容层（新代码直接导入 shared）。

## Flow

1. **初始化**：`game/track-context.ts` 的 `createTrackContext(def)` 从 `createTrackFromDef(def)` 生成 `Segment[]`，按 `getEnvironmentProfile(def.environment)` 驱动 `createRoadsideSprites`（环境密度/树色/形状），预计算曲率前缀和（`buildCurvePrefixSum`）、景物段索引（`buildSpriteIndex`）与道路段（`buildRoadStrips`），并生成车流（`createTraffic(lapLength, 777, count, TRAFFIC_SPAWN_SAFE_ZONE)`，count 取 `def.trafficCount ?? TRAFFIC_DEFAULT_COUNT`）；`game-loop.ts` 构造 `Renderer(canvas, segments, w, h, dpr, sprites, traffic)`（构造时构建默认（plains）day/night 两套远山离屏位图 + 曲率前缀和 + 景物索引 + 雨滴数据与离屏雨丝 canvas；远山按环境懒重建见 Design），分屏/预览渲染时经 `viewFor(ctx, boostParticles?)` 组装 `RenderView`（含 `night: ctx.def.timeOfDay === 'night'`、`environment: ctx.def.environment`、M8 speedRatio/boosting、M16 collisionFlash、H2 steer 与可选 `boostParticles`——比赛渲染传 game 层维护的尾焰粒子数组，菜单预览不传）。
2. **每帧驱动**（60fps）：外部更新相机（`cameraZ` 由车辆前进推进，`setCameraX` 设置横向偏移），调用 `render(cameraZ, smoke, timeSec, view?, renderOpts?)`；分屏时左右半屏各一次 `renderRegion(cameraZ, viewX, viewW, smoke, timeSec, view?, renderOpts?)` 后调用 `drawDivider(w / 2)`。
3. **renderWithOpts 核心管线**（`render` / `renderRegion` 共用）：
   - 视图解析：显式 `view` 优先，缺省回退到 this 字段构造的 `RenderView`。
   - 环境解析：M17 `envForMountains = view?.environment ?? 'plains'` 与 `currentEnv` 不一致时按环境懒重建 day/night 远山离屏缓存（切换赛道重建一次）。
   - 背景层：`updateLighting(timeSec, overcast, raining, night, environment)` 求昼夜 + 天气 + 夜晚 + 环境配色（`phase = floor(timeSec / WEATHER_CYCLE_SECONDS) % 3`，0 晴 / 1 阴 / 2 雨各 45s 循环，`overcast = phase === 1`、`raining = phase === 2`、`night = view?.night ?? false`、`environment = view?.environment ?? 'plains'`）→ 填充天空渐变（skyTop→skyBottom，至 horizon）→ 逐层 `drawMountainLayerCached` 视差平铺远山（night 用 `mountainsNight` 深色缓存）→ 填充草地（grass）→ `drawTerrain` 地形装饰（dunes/sea/rock，仅对应环境绘制；M18 起传累计时间 timeSec——沙丘 sin 变形折线路径、海面波浪 y 随 time 轻微漂移）。
   - 路面层：`trackIndexForCameraZ` 定位起点分段，自相机处向前迭代 `maxK` 段（`renderOpts?.drawDistance ?? DRAW_DISTANCE`(120)）；`renderRoadSurface` 内部每段 `projectSegmentQuad` 求当前/下一段四边形投影（`curveSum` 为当前中心线偏移、`curveSum + segment.curve` 为下一段）——优先消费 roadStrip 离屏缓存（`useCache`：视图赛道与缓存赛道同引用 + 缓存非空 + 段映射长度匹配时逐段切片 `drawCachedSegment`），miss/无映射时回退 `drawFallbackSegment`（路面 3 带渐变 + 双路缘）；雨天叠加 `WET_OVERLAY_COLOR` 压暗 + 近处（k<30）中心高光条；`shouldDrawCenterLine` 每两段绘制一次中心线虚线（仅 fallback 路径，缓存路径已烘焙）；`wrappedIndex === 0 && k < 40` 时绘制起终点线（16×2 黑白棋盘格）；M18 起每段在道路层之后追加 `drawCurbDetail` 路缘立体感细节（内侧暗色分隔线 shadeColor 0.75 + 外侧高光条 shadeColor 1.15，屏幕空间 2px 细分、路缘宽 <6px 跳过，两条路径共享）；最后 `curveSum += segment.curve`。
   - 世界物体层：`drawWorldObjects` —— `spritesInRangeIndexed`（段索引 O(候选段数)，`spriteScratch` 复用数组）投影景物 + `projectTraffic` 投影车流，按 z 降序双指针归并绘制：景物经 `drawSpriteProjected`（`curveOffsetAtZ` 减去相机自身曲率偏移后 `project`，`clampSpriteHeight` 限高 + M18 `clampSpriteScale` 近距缩放上限）按 kind switch 分发 `drawTree` / `drawCactus`（scale，M18 按投影 scale 远近两档明暗）/ `drawPalm`（rotation）/ `drawSnowpile` / `drawLamp`；车流经 `drawSingleTraffic`（night 时尾灯 + `drawHeadlight` 光晕）。
   - 雾层：`drawDistanceFog(ctx, opts, colors.skyBottom)` 远端雾霾渐变（消除远端密集条纹）。
   - 烟雾层：`projectSmoke` 过滤相机后方粒子，半径随 `scale` 缩放（`max(scale * height * 0.06, 2)`）、透明度随存活时间衰减（`max(1 - t / 0.6, 0) * 0.4`），绘制半透明圆 `rgba(200, 200, 210, alpha)`（fillStyle 经 `getFillStyle` 归一化键缓存）。
   - BOOST 尾焰层（H2）：view 带 `boostParticles` 且未 skip 时逐粒投影绘制橙色尾焰圆（`rgba(255, 180, 80, alpha)`，透明度随存活 t/0.6 衰减，仿 smoke），位于烟雾层之后。
   - 玩家车层（P0）：未 `skipPlayerCar` 时 `drawPlayerCar` 绘制屏幕底部固定精灵（laneOffset = camera.x、night、boosting = 未 skip 且 boostParticles 非空、steer = v.steer、M18 flash = v.collisionFlash、headlightColor = 环境配置）。
   - 雨层（P5 + F5）：`raining` 且未 `skipRain` 时 `drawRain` 平铺离屏雨丝 canvas（最上层特效，忽略投影；双幅 drawImage 按 timeSec 以 600px/s 下落并环形回绕，帧内零逐段绘制）。
   - 特效层（M8/M16）：`drawSpeedLines`（speedRatio > 0.7 时屏幕边缘 8 条径向条纹）→ `drawBoostVignette`（boosting 金色暗角）→ `drawCollisionVignette`（collisionFlash 红色暗角，alpha 0.45×flash）。
4. **renderRegion 裁剪流程**：`buildOpts(viewW, opts.height)` 重建区域投影参数 → `Math.round` 整数对齐 `viewX` / `viewW` → `ctx.save` → `translate(ox, 0)` → `rect(0, 0, ow, height)` 裁剪 → `renderWithOpts` → `ctx.restore`。
5. **分屏收尾**：`drawDivider(x, width = 4)` 在 `restore` 后用全屏坐标绘制全高 4px 深色渐变竖线（`createLinearGradient`：两侧透明 → 中心 `rgba(0,0,0,0.65)` → 两侧透明），覆盖交界瑕疵。
