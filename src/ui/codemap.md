# src/ui/

## Responsibility

游戏 UI 表现层的全部职责：HUD（P1/P2 速度、圈数、计时、最佳时间、漂移指示与连击倍率、得分达上限的 MAX 标记、碰撞计数；热座模式附加当前驾驶玩家标签与单屏 P2 BEST）的每帧刷新（分屏时双人并行）、启动/暂停/结算屏幕的显隐切换与结算面板多模式填充（分屏按完赛标记分 P1/P2 行并加 P1 前缀与 P1 LAP/P2 LAP 圈速前缀、热座回合快照与胜负比较、分屏漂移竞速横幅、热座/分屏分胜负的胜场统计行、挑战模式限时刷分结算——含达标/未达标展示）、暂停菜单控件（总音量/音乐/音效三 slider、重开/退出/继续按钮与触屏悬浮暂停按钮，事件由 GameLoop 绑定）、显示格式化（速度、时间、圈速）、按「赛道 × 玩家」双维度持久化最佳成绩（localStorage，P2 用 `-p2` 后缀 key）与双人模式持久化（胜场统计/连胜、漂移得分 TOP10——条目含最高连击档位、分屏漂移对局最近 10 局）、对局阶段 FSM 常量与转移函数直接自 src/shared 层导入（Phase 定义与转移逻辑唯一真源在 `src/shared/phase`/`phase-logic`，game 层保留同名兼容层）、以及触屏设备的虚拟摇杆输入（含暂停时清理残留输入的 `reset`，触屏设备摇杆常驻右下角）。UI 层不持有游戏逻辑：它接收 `RaceState`/`CarConfig`/`TrackContext`（类型均自 `src/shared/types` 导入）作为输入并产生 DOM 副作用（render-as-function-of-state）；挑战倒计时与 BOOST 条等特殊 HUD 元素仅声明类型，显隐/文本由 GameLoop 帧块直接操作；以及小地图/赛道进度指示器（`Minimap` 类：按赛道分段预计算轨迹折线并归一化，每帧按玩家进度重绘位置点，见 Files 表）。**依赖方向（2026-08-05 解环后）**：ui → `src/shared`（运行时常量/阶段/圈数/类型真源）+ `src/physics`（仅 import type）+ `src/engine`（minimap 的 `SEGMENT_LENGTH`）；对 `src/game` 完全断开——连 RaceState/TrackContext 类型也已提升至 shared/types，无任何 import（含 type）。

## Design

- **状态驱动渲染**：UI 模块均不缓存游戏状态，由调用方（`GameLoop`）每帧传入最新 `RaceState`/`CarConfig`；`updateHud` 每帧调用（9 参，含双人最佳时间 `bestTime2` 与热座尾参 `hotseatPlayer: 1|2|null`，默认 null 时行为与旧 8 参完全一致），`applyPhaseToScreens` 仅在阶段切换时调用。
- **DOM 引用集中管理**：`HudElements` / `ScreenElements` 两个接口聚合全部相关 DOM 元素（P2 元素及热座/胜场/暂停控件以 `?` 可选标注，`driftCombo`/`pauseVolume`/`pauseRestart`/`pauseMusicVolume`/`pauseSfxVolume`/`pauseQuit`/`finishRestartBtn`/`pauseTitle`/`finishCard2` 等均含）、分屏布局类 `hudContainer`/`hud2Container`（split 类切换），由 `GameLoop` 构造函数经 `$()` 一次性查询填充，UI 函数仅依赖接口而非具体 id，降低与 index.html 结构的耦合。
- **Phase 下沉后的直接导入（2026-08-05 兼容层移除）**：阶段常量/类型与转移函数唯一真源在 `src/shared/phase.ts` / `src/shared/phase-logic.ts`；`hud.ts`/`screens.ts` 直接自该层导入（原 `gamestate.ts` re-export 兼容层因 src 内 0 消费方已删除，`gamestate.test.ts` 同步改从 shared 导入），game 层同名文件亦 re-export 同一真源。
- **类型提升（shared/types）**：`RaceState` / `TrackContext` 接口唯一真源在 `src/shared/types.ts`（仅 `import type`，运行时无依赖）；ui 各模块（hud/screens/minimap）直接自该模块导入类型，`src/game/state.ts` 与 `src/game/track-context.ts` 保留同名 re-export 兼容层——ui → game 的 import type 依赖亦告消除，依赖方向完全断开。
- **存档玩家维度 key + storage 可注入**：`save.ts` 用 `playerSuffix(playerIndex)` 生成 key 后缀——P1 无后缀（与旧 key 完全一致，向后兼容）、P2 追加 `-p2`；`storage` 参数默认 `getStorage()`（`localStorage` 不可用时安全降级为 `null`），便于单测注入 mock；旧 API（`loadBestTime` 等）作为委托 P1 的兼容层保留。
- **双人持久化 API（胜场统计 + 漂移 TOP10）**：`save.ts` 提供 `WinStats`（p1/p2 胜场 + 连胜场次与连胜玩家）与 `winsKeyFor(mode)`（`outrun-pseudo3d-wins-hotseat` / `-split` 两模式独立 key）、`loadWins`（缺省/JSON 损坏/不可用回退 `{0,0,0,null}`）、`recordWin`（读旧 → 对应玩家 +1 → 同玩家连胜 +1 / 换玩家归 1 → 写回 → 返回新统计，storage 不可用仅返回内存结果）；漂移 TOP10 为跨玩家共享榜单：`DriftEntry { player, trackId, score, time, combo? }`（可选 `combo?: number` 最高连击档位——排行榜权重展示，旧 4 字段条目无此字段不丢）、`DRIFT_TOP_KEY`（`outrun-pseudo3d-drift-top`）、`DRIFT_TOP_MAX = 10`、`loadDriftTop`（JSON 损坏/非数组/不可用回退 []，成功按 score 降序）、`addDriftScore`（追加 → 降序稳定排序（同分保持插入序）→ 截断 10 → 写回 → `{ top, entered }`）。
- **对局记录（最近 10 局）**：`save.ts` 提供 `MatchEntry { winner: 'P1'|'P2'; p1Score; p2Score; trackId }`、`MATCH_TOP_KEY`（`outrun-pseudo3d-match-top`）、`MATCH_TOP_MAX = 10`、`loadMatchTop`（JSON 损坏/不可用/非数组回退 []，逐条校验 winner ∈ {P1,P2}/score 有限数/trackId 字符串，保持存储顺序）、`addMatchResult`（**最近 10 局语义**：新局 `unshift` 到头部 → `slice` 截断 → 写回 → `{ top, entered }`，storage null 仅返回内存结果）；GameLoop `refreshMatchTop` 渲染菜单 `#match-top`。
- **fillFinishPanel 多模式填充（完赛标记 + 热座/竞速/胜场/挑战选项驱动）**：`FinishPanelOptions { splitMode, finishedP1, finishedP2, hotseatMode, hotseatRound, prevP1Time, driftWinner, winStats, challengeMode }`（9 字段）由 `GameLoop` 计算传入——完赛标记按各玩家世界圈长/总圈数，`driftWinner` 为分屏双完赛时的漂移得分胜者（平局归 P1，非分屏恒 null），`winStats` 为 `recordWin` 后的最新统计（平手/单人不记时 null）；**挑战分支**（hotseat 快照分支前）：`finishTime` 显示「挑战结束」、`finishBest` 显示漂移榜排名（`loadDriftTop()` 按本局 `Math.round(score)` findIndex → `漂移榜第 N 名`，无匹配空）、`finishScore` 显示「挑战漂移得分 X · 达标/未达标（目标 N）」+ NEW DRIFT RECORD/最高复用（目标分自 `src/shared/constants` 的 `CHALLENGE_TARGET_SCORE` 导入）、`finishLaps` 空；P1 完赛填充总用时/平均速度/纪录判定/漂移得分/各圈用时（分屏时各行加 `P1 ` 前缀；圈速行 `finishLaps` 分屏加 `P1 ` 前缀、与 P2 对称），未完赛仅显示「未完赛」一行（分屏加 P1 前缀）；热座 round 2 时 P1 行改显示上一回合快照用时（`P1 用时 …`，不写存档、不显示纪录横幅，防止覆盖 P1 纪录）；P2 结算卡片容器 `finishCard2` 仅分屏/热座 round 2 时显示（其余模式整卡隐藏防空边框），P2 行在此分支填充并显式控制 `hidden`（视觉缺陷修复），圈速行 `finishLaps2` 恒加 `P2 ` 前缀；空行自动隐藏（`hideIfEmpty`：textContent 为空的行/边框卡隐藏，2026-08-05 空方框修复）；`finishHint` 承载热座交棒提示（round 1「按回车，P2 开始」）与胜负横幅（round 2 比较 `prevP1Time` 与 P2 用时：更快/平手），`finishDriftWinner` 显示分屏漂移竞速横幅（`DRIFT 竞速 · P1/P2 获胜！` + p1/p2 配色类），`finishWins` 显示胜场统计行（`胜场统计 · P1 x : y P2 · X 连胜 N`，winStats 非 null 时可见）；`race.finishShown` 守卫保证每局只填充一次。
- **updateHud 双人 BEST、热座标签、漂移连击与 MAX 标记**：P2 元素显隐统一由 `updateHud` 处理（非分屏全部隐藏），`hudBest2` 显示条件为 `splitMode && bestTime2 !== null`；**热座 P2 回合主 HUD 数据源切换（P0 修复）**：`hotseatPlayer === 2` 时主 HUD（速度/圈数/计时）改读 `race.player2` 与 `tracks[1]` 赛道参数、主 `BEST` 改显示 `bestTime2`，单屏 P2 用独立元素 `hudBestP2`（`hidden = splitMode || hotseatP2 || bestTime2 === null`，文本 `P2 BEST …`，热座 P2 回合隐藏避免重复展示）；`hudPlayerTag` 按 `hotseatPlayer` 显示「P1/P2 驾驶中」并切换 p1/p2 配色类（非热座隐藏）；漂移指示按 `hotseatPlayer === 2 ? race.player2 : race.player1` 读取当前驾驶玩家；**P2 漂移连击倍率**：可选 `driftCombo` 元素在 `active && combo >= 1` 时显示 `COMBO x(1+combo*0.25).toFixed(2)`（combo 已在 drift.ts 内 clamp 到 COMBO_MAX=10，倍率上限 3.5x），`!showHud` 分支一并隐藏；**MAX 标记**：漂移得分达 `DRIFT_SCORE_MAX`（99999，自 `src/shared/constants` 导入）时 `driftScoreValue` 显示 `MAX`，否则 `String(Math.round(score))`（与旧格式逐字一致）；P1 圈数按 `tracks[0]`、P2 按 `tracks[1]` 各自赛道世界（圈长/总圈数）计算；**碰撞计数**：可选 `hudCollision` 元素（`#hud-collision`）在比赛阶段且 `race.collisionCount > 0` 时显示 `碰撞 ×N`（0 时隐藏避免常态噪音，红色警示色）。
- **暂停菜单控件**：`ScreenElements` 含可选 `pauseVolume?: HTMLInputElement`（`#pause-volume` 总音量 input range 0-100）、`pauseRestart?: HTMLButtonElement`（`#pause-restart` 重开按钮）、`pauseResume?: HTMLButtonElement`（`#pause-resume` 继续按钮）与分轨音量 `pauseMusicVolume?`/`pauseSfxVolume?`（音乐/音效 slider）、`pauseQuit?: HTMLButtonElement`（`#pause-quit-btn` 返回菜单按钮，2026-08-05 文案由「退出游戏」改为「返回菜单」）、`pauseTitle?: HTMLHeadingElement`（分屏时动态标注暂停玩家）、`pauseTrackName?: HTMLParagraphElement`（`#pause-track-name`，2026-08-05 P2-6 进入暂停时显示当前赛道名）；`HudElements` 含可选 `pauseBtn?: HTMLButtonElement`（`#pause-btn` 触屏悬浮暂停按钮，RACING 阶段显示）；事件均由 GameLoop 构造器绑定（`input` → `setVolume`/`setMusicVolume`/`setSfxVolume(Number(value)/100)`、restart/quit click → 回菜单、pause-btn/pause-resume click → `applyPhase(togglePause(phase))`），元素恒存在、随 `#pause-screen` 面板显隐。
- **挑战倒计时与 BOOST 条（仅类型声明）**：`HudElements` 加可选 `challengeTimer?: HTMLDivElement`（`#challenge-timer`）与 `boostBar?: HTMLDivElement`（`#boost-bar`）——`updateHud` 不干预，显隐与文本/宽度由 GameLoop 帧块直接操作（挑战剩余秒数 `剩余 X.Xs`；2026-08-05 P1-1 起 BOOST 条为「固定 200px 轨道 + `.boost-fill` 填充层」，帧块经 `querySelector('.boost-fill')` 设填充宽度 `Math.round(charge×200)px`，轨道常驻显示未蓄能空槽）。
- **joystick 死区与 reset**：`offsetToInput` 以 `DEADZONE = 0.15 × radius` 半径判定归零（`steer`/`throttle` 均置 0），`brake` 阈值 0.2，位移按 `RADIUS = 60` 钳制归一化；仅处理 `pointerType === 'touch'`，不影响键盘/鼠标操作；**触屏设备常驻**：`JoystickUI` 构造时按 `maxTouchPoints`/`ontouchstart` 判定 `isTouchDevice`，常驻摇杆加 `touch-visible` 类（CSS fixed 右下角），非触屏保持按下才显示；**`reset()`**：清空 `activeId`/输入缓存并恢复非激活态——触屏设备清除内联定位回到右下角常驻、非触屏 `display: none`，供 GameLoop 进入 PAUSED 时调用（防恢复首帧残留输入）；**`JoystickInput` 加可选 `boost?: boolean`**（摇杆恒不产出，undefined 与 CarInput.boost 兼容）。
- **纯函数与副作用分离**：`format.ts` 为无副作用纯函数（`lapFromZ` re-export 自 shared）；`hud.ts`/`screens.ts`/`joystick.ts` 为 DOM 副作用模块；`save.ts` 的副作用通过可注入 `storage` 参数隔离；`minimap.ts` 每帧重绘为 Canvas 副作用，轨迹预计算纯函数化。
- **M18 UI/UX 深度打磨（2026-08-05）**：
  - 可访问性：index.html 为赛道按钮 `track-option-*` 加 `tabindex="0" role="button" aria-pressed aria-label`，榜单卡片 `.lb-card-clickable` 加 `tabindex="0" role="button" aria-expanded`，暂停按钮加 `aria-label="暂停"`，暂停屏加 `role="dialog" aria-modal aria-labelledby="pause-title"`，倒计时覆盖层加 `aria-live="polite"`；CSS 集中定义 `:focus-visible` 焦点环（赛道按钮、暂停控件、结算按钮、榜单卡片）。
  - 减少动画：`style.css` 新增 `@media (prefers-reduced-motion: reduce)`，关闭无限循环动画并将淡入改为纯 opacity 过渡。
  - 颜色令牌化：`style.css` `:root` 新增 `--color-p1/--color-p2/--color-danger/--color-accent` 及对应 RGB 变量，替换硬编码色值；P1/P2 配色类用于热座标签、分屏高亮、结算横幅等。
  - 屏幕切换过渡：`game-loop.transitionScreenOut` 为屏幕元素加 `.leaving` 触发 CSS 退场淡出（150ms），`screens.setHidden` 识别 `.leaving` 避免与 transitionend 冲突；暂停屏入场使用 `.pause-in` 淡入。
  - HUD 反馈增强：`hud.ts` 漂移得分数字变化时给 `#drift-score-value` 加 `.score-pop` 触发一次性放大回弹（250ms）；`game-loop` 检测 BOOST 未蓄能（Space/Enter 按下且 `boostCharge <= 0`）时给 `#boost-bar` 加 `.no-charge` 红闪反馈。
  - 文案同源：新增 `RACING_TOUCH_HINT`（比赛中触屏引导浮层）、`FINISH_DRIFT_HINT`（P1 结算零漂移提示）、`MATCH_EMPTY_HINT`/`STATS_EMPTY_HINT`（榜单空态占位），均来自 `copy.ts` 唯一真源；`top-refresh.ts` 与 `screens.ts` 消费这些常量渲染空态与结算提示。
  - 触屏引导：`game-loop` 在首次进入 `PHASE_RACING` 时显示 `#racing-touch-hint` 浮层（CSS `(hover: none)` 下 2s 淡出），内容取自 `RACING_TOUCH_HINT`。
  - 样式整理：`style.css` 将 `#start-btn` 与 `#finish-restart-btn` 公共样式抽为 `.btn-primary`，自定义 `menu-content`/`finish-screen` 滚动条，低高度移动端压缩菜单（隐藏榜单占位文案与赛道名、缩小开始按钮、调整光晕位置防重叠）。

## Flow

1. **启动组装**：`main.ts` 仅调用 `initGame()` → `GameLoop` 构造——`$()` 查询 DOM 组装 `HudElements`/`ScreenElements`（含 `pauseBtn`/`pauseResume`/`pauseMusicVolume`/`pauseSfxVolume`/`pauseQuit`/`finishRestartBtn`/`pauseTitle`，构造器绑定 pause-btn/pause-resume click → `togglePause`、音乐/音效 slider input → `setMusicVolume`/`setSfxVolume`）、创建 `TrackManager`/`CarConfig`/`RaceState`/`Renderer`/`createInputManager`、`new JoystickUI().attach(canvas)`；从 `save.ts` 读取双人最佳：`loadBestTime(trackId0)` 与 `loadBestTimeFor(1, trackId1)`；初始阶段 `PHASE_MENU`，监听 keydown/resize 并启动 `requestAnimationFrame(frame)`。
2. **主循环（每帧）**：`GameLoop.frame()` 在 `PHASE_RACING` 下推进双世界车流与 `updatePlayerFrame`（热座模式输入只路由到当前回合玩家 `hotseatPlayer`，另一玩家不更新；非热座 P1/P2 各自更新），`updateCollisions`，并按各玩家世界圈长计算完赛标记（`finishedP1`/`finishedP2`——分屏或热座时 P2 独立判定，单屏 P2 恒 false），任一完赛即 `applyPhase(PHASE_FINISHED)`；随后渲染并调用 `updateHud(...)`（尾参 `hotseatPlayer = hotseatMode ? this.hotseatPlayer : null`）刷新双人 HUD——P1 速度经 `formatSpeed` 换算 km/h、圈数经 `lapFromZ` + `formatLap`、计时经 `formatTime`，P2 同理取 `tracks[1]`，`BEST`/`BEST2` 由 `bestTime`/`bestTime2` 驱动（热座 P2 回合主 BEST 显示 bestTime2），漂移指示与连击倍率（`driftCombo`）、得分 MAX 标记取当前回合玩家。
3. **键盘事件**：`onKeyDown`——Escape → `togglePause(this.phase)`（触屏等效：`#pause-btn`/`#pause-resume` click 经构造器绑定同走 `togglePause`）；`PHASE_MENU` 下数字键 1-9 选 P1 赛道（分屏时 Shift+1-9 选 P2，原 7/8/9 键位废弃；热座时选赛道同步 P2 世界为同一赛道；无效数字键与单独按下的修饰键均静默吞掉，不触发「任意键开始」）；`PHASE_FINISHED` 热座 P1 回合按 Enter/R 交棒——快照 `prevP1Time = player1.raceTime`、`hotseatPlayer` 置 2、`resetRace()` 后直接回到 `PHASE_RACING`（Phase 保持四态，不经过 nextPhase）；其余键 → `nextPhase(phase, lapFromZ(cameraZ, lapLength), totalLaps)` 推进阶段。
4. **applyPhaseToScreens（opts 双人完赛标记 + 热座/竞速/胜场选项）**：`applyPhase(newPhase)` 以 `lapFromZ` 对比 `totalLaps` 计算 `finishedP1`/`finishedP2`，分屏双完赛时按漂移得分比较得 `driftWinner`（平局归 P1），连同 `hotseatMode`/`hotseatRound`（= `hotseatPlayer`）/`prevP1Time`/`winStats`（`FINISHED && !finishShown` 时 `recordWin` 的返回，平手/单人 null）构造 `FinishPanelOptions` 传入 `applyPhaseToScreens` 切换屏幕显隐（FINISHED 块内另按正分条件调 `addDriftScore`——附 `combo: Math.round(driftState.combo)` 最高连击档位——与分屏双完赛 `addMatchResult`，随后 `refreshDriftTop`/`refreshMatchTop` 刷新菜单榜单）：进入 `PHASE_FINISHED` 触发 `fillFinishPanel`（热座 round 2 显示胜负横幅与胜场统计行）；进入 `PHASE_MENU` 由 GameLoop 负责 `resetRace()` 重建对局（完赛/重置后重新 `loadBestTime`/`loadBestTimeFor(1, ...)` 刷新 HUD 双人 BEST，并 `refreshDriftTop()` 刷新 `#drift-top` 榜单）。
5. **结算填充与存档**：`fillFinishPanel`（`finishShown` 守卫）挑战模式分支（`challengeMode` 时 `finishTime` '挑战结束'/`finishBest` 漂移榜排名/`finishScore` `挑战漂移得分 X · 达标/未达标（目标 N）` + NEW DRIFT RECORD 复用/`finishLaps` 空）；常规模式对 P1 调 `saveBestTime`/`saveBestDriftScore`（P2 调 `saveBestTimeFor(1, ...)`/`saveBestDriftScoreFor(1, ...)`），仅刷新纪录时写入并返回 `true`，据此显示 `NEW RECORD!` / `NEW DRIFT RECORD!`，并用 `formatLapTimes` 展示各圈用时；分屏 P1 行各字段加 `P1 ` 前缀、圈速行 `finishLaps` 分屏加 `P1 ` 前缀、P2 圈速行 `finishLaps2` 恒加 `P2 ` 前缀；热座 round 2 的 P1 行改为只显示 `prevP1Time` 快照（跳过存档逻辑），P2 行按 `finishCard2` 分支填充（分屏/热座 round 2 时显示，含显式 hidden 控制）；末尾按模式填 `finishHint`（交棒提示/胜负横幅）、`finishDriftWinner`（分屏漂移竞速横幅）与 `finishWins`（胜场统计行，`winStats` 非 null 时可见），并对空行执行 `hideIfEmpty`。
6. **localStorage 持久化**：`save.ts` 按 `BEST_TIME_PREFIX`/`BEST_DRIFT_PREFIX` + 赛道 id + 玩家后缀生成 key；读写均经 `Number.isFinite` 校验，写入前比较旧纪录（时间更短/分数更高才写）；另有 `WIN_STATS_PREFIX`（hotseat/split 独立 JSON 胜场）与 `DRIFT_TOP_KEY`（跨玩家 JSON 榜单，条目含可选 `combo` 字段，旧条目不丢），均 try/catch 回退默认。
