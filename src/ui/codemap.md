# src/ui/

## Responsibility

游戏 UI 表现层的全部职责：HUD（P1/P2 速度、圈数、计时、最佳时间、漂移指示与连击倍率、得分达上限的 MAX 标记；热座模式附加当前驾驶玩家标签与单屏 P2 BEST）的每帧刷新（分屏时双人并行）、启动/暂停/结算屏幕的显隐切换与结算面板多模式填充（分屏按完赛标记分 P1/P2 行并加 P1 前缀与 P1 LAP/P2 LAP 圈速前缀、热座回合快照与胜负比较、分屏漂移竞速横幅、热座/分屏分胜负的胜场统计行、M12 挑战模式限时刷分结算）、暂停菜单控件（总音量/音乐/音效三 slider、重开按钮、继续按钮与触屏悬浮暂停按钮，事件由 GameLoop 绑定）、显示格式化（速度、时间、圈速）、按「赛道 × 玩家」双维度持久化最佳成绩（localStorage，P2 用 `-p2` 后缀 key）与双人模式持久化（胜场统计/连胜、漂移得分 TOP10——H4 起条目含最高连击档位、分屏漂移对局最近 10 局）、对局阶段 FSM 的 re-export 兼容层（Phase 定义与转移逻辑已下沉至 game 层）、以及触屏设备的虚拟摇杆输入（含暂停时清理残留输入的 `reset`）。UI 层不持有游戏逻辑：它接收 `RaceState`/`CarConfig`/`TrackContext` 作为输入并产生 DOM 副作用（render-as-function-of-state）；挑战倒计时与 BOOST 条等特殊 HUD 元素仅声明类型，显隐/文本由 GameLoop 帧块直接操作。

## Design

- **状态驱动渲染**：UI 模块均不缓存游戏状态，由调用方（`GameLoop`）每帧传入最新 `RaceState`/`CarConfig`；`updateHud` 每帧调用（9 参，含双人最佳时间 `bestTime2` 与热座尾参 `hotseatPlayer: 1|2|null`，默认 null 时行为与旧 8 参完全一致），`applyPhaseToScreens` 仅在阶段切换时调用。
- **DOM 引用集中管理**：`HudElements` / `ScreenElements` 两个接口聚合全部相关 DOM 元素（P2 元素及热座/胜场/暂停控件以 `?` 可选标注，M10 新增 `driftCombo`/`pauseVolume`/`pauseRestart`，M11 F3 新增 `pauseBtn`/`pauseResume`），由 `GameLoop` 构造函数经 `$()` 一次性查询填充，UI 函数仅依赖接口而非具体 id，降低与 index.html 结构的耦合。
- **Phase 下沉后的 re-export 兼容层**：阶段常量/类型与转移函数已下沉到 `game/phase.ts` / `game/phase-logic.ts`，`gamestate.ts` 仅保留 `export { ... } from ...` 语句，维持 screens/hud/单测等旧消费方的导入路径不变。
- **存档玩家维度 key + storage 可注入**：`save.ts` 用 `playerSuffix(playerIndex)` 生成 key 后缀——P1 无后缀（与旧 key 完全一致，向后兼容）、P2 追加 `-p2`；`storage` 参数默认 `getStorage()`（`localStorage` 不可用时安全降级为 `null`），便于单测注入 mock；旧 API（`loadBestTime` 等）作为委托 P1 的兼容层保留。
- **M9 双人持久化 API（胜场统计 + 漂移 TOP10）**：`save.ts` 新增 `WinStats`（p1/p2 胜场 + 连胜场次与连胜玩家）与 `winsKeyFor(mode)`（`outrun-pseudo3d-wins-hotseat` / `-split` 两模式独立 key）、`loadWins`（缺省/JSON 损坏/不可用回退 `{0,0,0,null}`）、`recordWin`（读旧 → 对应玩家 +1 → 同玩家连胜 +1 / 换玩家归 1 → 写回 → 返回新统计，storage 不可用仅返回内存结果）；漂移 TOP10 为跨玩家共享榜单：`DriftEntry { player, trackId, score, time, combo? }`（**H4** 起新增可选 `combo?: number` 最高连击档位——排行榜权重展示，旧 4 字段条目无此字段不丢）、`DRIFT_TOP_KEY`（`outrun-pseudo3d-drift-top`）、`DRIFT_TOP_MAX = 10`、`loadDriftTop`（JSON 损坏/非数组/不可用回退 []，成功按 score 降序）、`addDriftScore`（追加 → 降序稳定排序（同分保持插入序）→ 截断 10 → 写回 → `{ top, entered }`）。
- **M11 对局记录（F2，最近 10 局）**：`save.ts` 新增 `MatchEntry { winner: 'P1'|'P2'; p1Score; p2Score; trackId }`、`MATCH_TOP_KEY`（`outrun-pseudo3d-match-top`）、`MATCH_TOP_MAX = 10`、`loadMatchTop`（JSON 损坏/不可用/非数组回退 []，逐条校验 winner ∈ {P1,P2}/score 有限数/trackId 字符串，保持存储顺序）、`addMatchResult`（**最近 10 局语义**：新局 `unshift` 到头部 → `slice` 截断 → 写回 → `{ top, entered }`，storage null 仅返回内存结果）；GameLoop `refreshMatchTop` 渲染菜单 `#match-top`。
- **fillFinishPanel 多模式填充（完赛标记 + 热座/竞速/胜场/挑战选项驱动）**：`FinishPanelOptions { splitMode, finishedP1, finishedP2, hotseatMode, hotseatRound, prevP1Time, driftWinner, winStats, challengeMode }`（9 字段，M12 G1 加 challengeMode）由 `GameLoop` 计算传入——完赛标记按各玩家世界圈长/总圈数，`driftWinner` 为分屏双完赛时的漂移得分胜者（平局归 P1，非分屏恒 null），`winStats` 为 `recordWin` 后的最新统计（平手/单人不记时 null）；**M12 挑战分支**（hotseat 快照分支前）：`finishTime` 显示「挑战结束」、`finishBest` 显示漂移榜排名（`loadDriftTop()` 按本局 `Math.round(score)` findIndex → `漂移榜第 N 名`，无匹配空）、`finishScore` 显示「挑战漂移得分 X」+ NEW DRIFT RECORD/最高复用、`finishLaps` 空；P1 完赛填充总用时/平均速度/纪录判定/漂移得分/各圈用时（分屏时各行加 `P1 ` 前缀，E1；圈速行 `finishLaps` 分屏加 `P1 ` 前缀、与 P2 对称，P1 任务），未完赛仅显示「未完赛」一行；热座 round 2 时 P1 行改显示上一回合快照用时（`P1 用时 …`，不写存档、不显示纪录横幅，防止覆盖 P1 纪录）；P2 行在分屏或热座 round 2 且元素存在时填充，并显式控制 `hidden`（视觉缺陷修复），圈速行 `finishLaps2` 恒加 `P2 ` 前缀（双人场景才出现，P1 任务）；`finishHint` 承载热座交棒提示（round 1「按回车，P2 开始」）与胜负横幅（round 2 比较 `prevP1Time` 与 P2 用时：更快/平手），`finishDriftWinner` 显示分屏漂移竞速横幅（`DRIFT 竞速 · P1/P2 获胜！` + p1/p2 配色类），`finishWins` 显示胜场统计行（`胜场统计 · P1 x : y P2 · X 连胜 N`，winStats 非 null 时可见）；`race.finishShown` 守卫保证每局只填充一次。
- **updateHud 双人 BEST、热座标签、漂移连击与 MAX 标记**：P2 元素显隐统一由 `updateHud` 处理（非分屏全部隐藏），`hudBest2` 显示条件为 `splitMode && bestTime2 !== null`；单屏热座用独立元素 `hudBestP2`（`hidden = splitMode || bestTime2 === null`，文本 `P2 BEST …`）；`hudPlayerTag` 按 `hotseatPlayer` 显示「P1/P2 驾驶中」并切换 p1/p2 配色类（非热座隐藏）；漂移指示按 `hotseatPlayer === 2 ? race.player2 : race.player1` 读取当前驾驶玩家；**M10 P2 漂移连击倍率**：可选 `driftCombo` 元素在 `active && combo >= 1` 时显示 `COMBO x(1+combo*0.25).toFixed(2)`（combo 已在 drift.ts 内 clamp 到 COMBO_MAX=10，倍率上限 3.5x），`!showHud` 分支一并隐藏；**M11 F6 MAX 标记**：漂移得分达 `DRIFT_SCORE_MAX`（99999，自 `game/constants` 导入）时 `driftScoreValue` 显示 `MAX`，否则 `String(Math.round(score))`（与旧格式逐字一致）；P1 圈数按 `tracks[0]`、P2 按 `tracks[1]` 各自赛道世界（圈长/总圈数）计算。
- **暂停菜单控件（P6 + F3 + G7）**：`ScreenElements` 新增可选 `pauseVolume?: HTMLInputElement`（`#pause-volume` 总音量 input range 0-100）、`pauseRestart?: HTMLButtonElement`（`#pause-restart` 重开按钮）、`pauseResume?: HTMLButtonElement`（`#pause-resume` 继续按钮，F3）与 M12 G7 `pauseMusicVolume?`/`pauseSfxVolume?`（音乐/音效分轨 slider）；`HudElements` 新增可选 `pauseBtn?: HTMLButtonElement`（`#pause-btn` 触屏悬浮暂停按钮，F3，RACING 阶段显示）；事件均由 GameLoop 构造器绑定（`input` → `setVolume`/`setMusicVolume`/`setSfxVolume(Number(value)/100)`、restart click → 回菜单、pause-btn/pause-resume click → `applyPhase(togglePause(phase))`），元素恒存在、随 `#pause-screen` 面板显隐，`applyPhaseToScreens` 无改动。
- **挑战倒计时与 BOOST 条（G1/G4，仅类型声明）**：`HudElements` 加可选 `challengeTimer?: HTMLDivElement`（`#challenge-timer`）与 `boostBar?: HTMLDivElement`（`#boost-bar`）——`updateHud` 不干预，显隐与文本/宽度由 GameLoop 帧块直接操作（挑战剩余秒数 `剩余 X.Xs`；BOOST 条宽度按 charge 相对 max-width 200px 的像素映射）。
- **joystick 死区与 reset**：`offsetToInput` 以 `DEADZONE = 0.15 × radius` 半径判定归零（`steer`/`throttle` 均置 0），`brake` 阈值 0.2，位移按 `RADIUS = 60` 钳制归一化；仅处理 `pointerType === 'touch'`，不影响键盘/鼠标操作；**F3 `reset()`**：清空 `activeId`/输入缓存并隐藏摇杆底盘（`display: none`），供 GameLoop 进入 PAUSED 时调用（防恢复首帧残留输入）；**G4 `JoystickInput` 加可选 `boost?: boolean`**（摇杆恒不产出，undefined 与 CarInput.boost 兼容）。
- **纯函数与副作用分离**：`format.ts` 与 `gamestate.ts` 为无副作用纯函数/纯 re-export；`hud.ts`/`screens.ts`/`joystick.ts` 为 DOM 副作用模块；`save.ts` 的副作用通过可注入 `storage` 参数隔离。

## Flow

1. **启动组装**：`main.ts` 仅调用 `initGame()` → `GameLoop` 构造——`$()` 查询 DOM 组装 `HudElements`/`ScreenElements`（含 M11 `pauseBtn`/`pauseResume`、M12 `pauseMusicVolume`/`pauseSfxVolume`，构造器绑定 pause-btn/pause-resume click → `togglePause`、音乐/音效 slider input → `setMusicVolume`/`setSfxVolume`）、创建 `TrackManager`/`CarConfig`/`RaceState`/`Renderer`/`createInputManager`、`new JoystickUI().attach(canvas)`；从 `save.ts` 读取双人最佳：`loadBestTime(trackId0)` 与 `loadBestTimeFor(1, trackId1)`；初始阶段 `PHASE_MENU`，监听 keydown/resize 并启动 `requestAnimationFrame(frame)`。
2. **主循环（每帧）**：`GameLoop.frame()` 在 `PHASE_RACING` 下推进双世界车流与 `updatePlayerFrame`（热座模式输入只路由到当前回合玩家 `hotseatPlayer`，另一玩家不更新；非热座 P1/P2 各自更新），`updateCollisions`，并按各玩家世界圈长计算完赛标记（`finishedP1`/`finishedP2`——分屏或热座时 P2 独立判定，单屏 P2 恒 false），任一完赛即 `applyPhase(PHASE_FINISHED)`；随后渲染并调用 `updateHud(...)`（尾参 `hotseatPlayer = hotseatMode ? this.hotseatPlayer : null`）刷新双人 HUD——P1 速度经 `formatSpeed` 换算 km/h、圈数经 `lapFromZ` + `formatLap`、计时经 `formatTime`，P2 同理取 `tracks[1]`，`BEST`/`BEST2` 由 `bestTime`/`bestTime2` 驱动，漂移指示与连击倍率（`driftCombo`，M10 P2）、得分 MAX 标记（M11 F6）取当前回合玩家。
3. **键盘事件**：`onKeyDown`——Escape → `togglePause(this.phase)`（触屏等效：`#pause-btn`/`#pause-resume` click 经构造器绑定同走 `togglePause`）；`PHASE_MENU` 下数字键 1-9 选 P1 赛道（分屏时 Shift+1-9 选 P2，原 7/8/9 键位废弃；热座时选赛道同步 P2 世界为同一赛道；无效数字键与单独按下的修饰键均静默吞掉，不触发「任意键开始」）；`PHASE_FINISHED` 热座 P1 回合按 Enter/R 交棒——快照 `prevP1Time = player1.raceTime`、`hotseatPlayer` 置 2、`resetRace()` 后直接回到 `PHASE_RACING`（Phase 保持四态，不经过 nextPhase）；其余键 → `nextPhase(phase, lapFromZ(cameraZ, lapLength), totalLaps)` 推进阶段。
4. **applyPhaseToScreens（opts 双人完赛标记 + 热座/竞速/胜场选项）**：`applyPhase(newPhase)` 以 `lapFromZ` 对比 `totalLaps` 计算 `finishedP1`/`finishedP2`，分屏双完赛时按漂移得分比较得 `driftWinner`（平局归 P1），连同 `hotseatMode`/`hotseatRound`（= `hotseatPlayer`）/`prevP1Time`/`winStats`（M9：`FINISHED && !finishShown` 时 `recordWin` 的返回，平手/单人 null）构造 `FinishPanelOptions` 传入 `applyPhaseToScreens` 切换屏幕显隐（FINISHED 块内另按正分条件调 `addDriftScore`——**H4** 起附 `combo: Math.round(driftState.combo)` 最高连击档位——与分屏双完赛 `addMatchResult`，随后 `refreshDriftTop`/`refreshMatchTop` 刷新菜单榜单）：进入 `PHASE_FINISHED` 触发 `fillFinishPanel`（热座 round 2 显示胜负横幅与胜场统计行）；进入 `PHASE_MENU` 由 GameLoop 负责 `resetRace()` 重建对局（完赛/重置后重新 `loadBestTime`/`loadBestTimeFor(1, ...)` 刷新 HUD 双人 BEST，并 `refreshDriftTop()` 刷新 `#drift-top` 榜单）。
5. **结算填充与存档**：`fillFinishPanel`（`finishShown` 守卫）挑战模式分支（M12 G1：`challengeMode` 时 `finishTime` '挑战结束'/`finishBest` 漂移榜排名/`finishScore` `挑战漂移得分 X` + NEW DRIFT RECORD 复用/`finishLaps` 空）；常规模式对 P1 调 `saveBestTime`/`saveBestDriftScore`（P2 调 `saveBestTimeFor(1, ...)`/`saveBestDriftScoreFor(1, ...)`），仅刷新纪录时写入并返回 `true`，据此显示 `NEW RECORD!` / `NEW DRIFT RECORD!`，并用 `formatLapTimes` 展示各圈用时；分屏 P1 行各字段加 `P1 ` 前缀（E1）、圈速行 `finishLaps` 分屏加 `P1 ` 前缀、P2 圈速行 `finishLaps2` 恒加 `P2 ` 前缀（P1 任务）；热座 round 2 的 P1 行改为只显示 `prevP1Time` 快照（跳过存档逻辑），P2 行按 `(splitMode || (hotseatMode && hotseatRound === 2)) && finishTime2` 存在性分支填充；末尾按模式填 `finishHint`（交棒提示/胜负横幅）、`finishDriftWinner`（分屏漂移竞速横幅）与 `finishWins`（胜场统计行，`winStats` 非 null 时可见）。
6. **localStorage 持久化**：`save.ts` 按 `BEST_TIME_PREFIX`/`BEST_DRIFT_PREFIX` + 赛道 id + 玩家后缀生成 key；读写均经 `Number.isFinite` 校验，写入前比较旧纪录（时间更短/分数更高才写）；M9 起另有 `WIN_STATS_PREFIX`（hotseat/split 独立 JSON 胜场）与 `DRIFT_TOP_KEY`（跨玩家 JSON 榜单，条目 H4 起含可选 `combo` 字段，旧条目不丢），均 try/catch 回退默认。

## Integration

- Consumed by:
  - `src/game/game-loop.ts`（`GameLoop`）：主循环与流程控制的主消费方——每帧 `updateHud`/`HudElements`（尾参 `hotseatPlayer`）、触屏 `JoystickUI`（F3 进入 PAUSED 时调 `reset()`）、阶段切换 `applyPhaseToScreens`/`ScreenElements`/`FinishPanelOptions`（热座/漂移竞速/胜场字段由 GameLoop 计算：`hotseatRound`/`prevP1Time`/`driftWinner`/`winStats`）、存档 `loadBestTime`/`loadBestTimeFor(1, ...)`/`recordWin`/`addDriftScore`/`loadDriftTop`（M9 胜场统计与漂移 TOP10，H4 起条目附 `combo`、`refreshDriftTop` 渲染 `#drift-top` 时对含 combo 条目追加 ` · 连击 x倍率` 后缀，旧条目不追加）与 `addMatchResult`/`loadMatchTop`（M11 F2 分屏对局 TOP10，`refreshMatchTop` 渲染 `#match-top`）；阶段常量/`nextPhase`/`togglePause` 直接取 `game/phase` 与 `game/phase-logic`（不经过 ui/gamestate）
  - `src/main.ts`：仅入口 `initGame()`（UI 消费逻辑已全部迁移至 GameLoop，不再直接使用 ui 模块）
  - `tests/unit/`：`hud.test.ts`、`gamestate.test.ts`、`format.test.ts`、`save.test.ts`、`joystick.test.ts` 分别对 `ui/hud`、`ui/gamestate`、`ui/format`、`ui/save`、`ui/joystick` 做单测
  - 内部消费：`hud.ts` → `format.ts`（`formatLap`/`formatSpeed`/`formatTime`/`lapFromZ`）与 `gamestate.ts`（`PHASE_PAUSED`/`PHASE_RACING`/`Phase`）；`screens.ts` → `format.ts`（`formatLapTimes`/`formatSpeed`/`formatTime`）、`save.ts`（8 个 load/save 函数）、`gamestate.ts`（`PHASE_*`）
- Depends on:
  - `src/physics/car.ts`：`CarConfig` 类型（`maxSpeed`，供 km/h 换算，320 对应满速）
  - `src/game/state.ts`：`RaceState` 类型（`player1`/`player2`/`tracks`/`lapTimes`/`lapTimes2`/`lastLap`/`lastLap2`/`finishShown`）
  - `src/game/track-context.ts`：`TrackContext` 类型（`def.id`/`lapLength`/`totalLaps`，HUD 圈数计算与存档 key 的来源）
  - `src/game/phase.ts` 与 `src/game/phase-logic.ts`：经 `gamestate.ts` re-export（`Phase`/`PHASE_*`/`nextPhase`/`togglePause`）
  - `src/game/lap.ts`：`lapFromZ` 经 `format.ts` re-export（圈数计算下沉后的兼容层）
  - index.html 对应 DOM 结构（`hud-*`/`hud-best-p2`/`hud-player-tag`、`drift-indicator`/`drift-score-value`/`drift-combo`（M10 P2 连击倍率）、`challenge-timer`（M12 G1 挑战倒计时）、`boost-bar`（M12 G4 BOOST 条）、`pause-btn`（M11 F3 触屏暂停悬浮按钮）、`start-screen`（含 `#best-summary` 各赛道 BEST 汇总、`#drift-top` 菜单榜单与 `#match-top` 对局榜）、`finish-*`/`finish-hint`/`finish-drift-winner`/`finish-wins`、`pause-screen`（含 `#pause-controls` 总音量/音乐/音效三 slider、继续按钮与重开按钮）、9 个 `track-option-*` 赛道按钮等 id 与 `joystick-base`/`joystick-knob` 样式类）
  - 浏览器 Web API：`localStorage`（`save.ts`，不可用时降级 `null`）、`PointerEvent`/`setPointerCapture`（`joystick.ts`，仅 touch 生效）
