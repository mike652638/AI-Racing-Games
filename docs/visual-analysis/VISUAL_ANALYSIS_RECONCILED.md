## 一、跨任务共识问题（三路 observer 同时报告）

### 1. 🔴 P0 · 玩家车辆精灵不可见（Critical）
- **A1 报告**：02/03 截图中玩家车辆几乎完全不可见，仅画面最底部边缘能检测到极少量灰/白像素残片；推测 Y 坐标计算有误、screenY 偏移过大、缩放因子过小或未被绑到正确渲染层
- **A2 报告**：分屏双视口（06-split-screen）中两屏都无玩家车辆渲染（仅看到道路前方），**暂停界面（04-paused）有半透明遮罩后车辆同样不可见**——是渲染层问题，不是被菜单遮挡
- **A3 报告**：06/07/15/22 四张全部缺失玩家车辆精灵；HUD 速度从 0 km/h 到 320 km/h 都有，但画面底部中央始终没有车
- **共识**：渲染层或 Z 顺序问题，不是输入或物理问题；优先级 **P0**

### 2. 🔴 P0 · 移动端触控 UI 完全缺失（Critical）
- **A2 报告**：未涉及移动端
- **A3 报告**：22_mobile_racing.png 移动端截图中"任何虚拟摇杆、加速/刹车按钮或其他触控 UI 元素都没有"，只有右下角暂停按钮；意味着移动端用户**根本无法操控车辆**
- **共识**：移动端不可用，优先级 **P0**

### 3. 🟠 P1 · 天空渲染垂直条纹伪影（High）
- **A1 报告**：02/03 截图中天空为深蓝/藏青，但出现大量垂直锯齿状条纹（vertical streak artifacts），像 Canvas 渐变 bug
- **A3 报告**：06/07/15 全部出现"深蓝色天空区域有明显的色带/条纹"，分屏两屏都存在
- **A2 报告**：夜间天空未明显报告此问题（夜间是深蓝近黑，本来就是纯色）
- **共识**：仅影响**白天**场景；可能是 `createLinearGradient` 颜色插值精度问题；优先级 **P1**

### 4. 🟠 P1 · 竖屏（移动端）透视严重畸变（High）
- **A3 报告**：22_mobile_racing.png 中画面被撕成上下两段——上半部分是缩小的伪 3D 视野、下半部分是另一套投影参数的近端道路直冲底部；两者消失点不一致，**视觉断裂**明显
- **A1/A2**：未涉及竖屏
- **共识**：仅影响移动端竖屏模式；优先级 **P1**

## 二、出现两次的问题（值得 P2 关注）

### 5. 🟡 P2 · HUD 速度始终显示 0 km/h（白天模式）
- **A1 报告**：02 截图 HUD 显示 0 km/h，03 截图 0:21.516 秒后仍显示 0；计时器在走说明游戏逻辑运行中，但速度表与车辆速度未正确绑定
- **A3 报告**：06_racing_start.png 起步时显示 0 km/h（但此时车辆确实静止）；07_racing_3s.png 已有 247 km/h 所以绑定了——可能是**起步阶段未刷新或单位换算问题**
- **结论**：A3 实际是 247/320 km/h 显示正常，**A1 报告的"始终为 0"可能是 observer 误读**（计时器从 3.7s → 21.5s 而速度仍 0，但 21 秒后游戏应该早就移动了）。需要在游戏中实测确认。**降级为待核实**

### 6. 🟡 P2 · 车辆精灵近距离过大 / 缺少裁剪
- **A2 报告**：分屏模式（15_split_racing_8s.png）左屏近处出现超大黄色圆形路灯"左边缘被截断"——近距离下精灵尺寸超界
- **A3 报告**：明确指出"当精灵距离摄像机极近时，应被裁剪或限制最大尺寸"
- **共识**：缺少精灵最大缩放上限 + 距离剔除；优先级 **P2**

### 7. 🟡 P2 · 路面近端（底部）空洞
- **A1 报告**：03 截图底部中心有少量灰白色形状，疑似车辆顶部残片
- **A3 报告**：06/07 截图底部灰色区域没有路面纹理，"显得空洞"；22 移动端下半部分中线从画面中央一直延伸到底部
- **共识**：路面近端缺少纹理/材质细节；优先级 **P2**

### 8. 🟡 P2 · 滑块控件缺少数值显示
- **A2 报告**：04-paused.png 暂停界面三个滑块（音量/音乐/音效）都没有显示当前数值（如 "80%"），用户无法知道当前设置
- **A1/A3**：未涉及暂停界面
- **共识**：暂停界面 UI 细节；优先级 **P2**

### 9. 🟡 P2 · 夜间模式缺少车灯照射效果
- **A2 报告**：07-night-canyon.png 截图中未观察到车辆前灯照亮前方路面的效果（夜间模式核心沉浸感元素）
- **A1/A3**：未涉及夜间车灯
- **共识**：夜间氛围增强；优先级 **P2**
