## 二、严重问题（必须立即修复）

### 2.1 菜单界面

#### C1. 路面分段渲染出灰色矩形块
- **位置**：屏幕下半部分，约占画面 30%
- **现象**：路面由纯灰色矩形条带构成，无纹理/渐变，像未完成的调试占位符
- **建议**：添加纹理填充或深灰→黑色渐变；菜单状态下使用半透明遮罩覆盖

#### C2. 赛道3名称 "S" 字符渲染断裂
- **位置**：按钮 3 及中央标题
- **现象**："S 弯挑战" 中 "S" 与 "弯挑战" 之间有明显空白断裂，字体不连贯
- **建议**：统一字体渲染，确保 "S弯" 作为整体显示

#### C3. 赛道9按钮文字被背景遮挡
- **位置**：第 9 号按钮 "山岳险道 ★★☆"
- **现象**：文字被树木/路灯精灵元素部分遮挡，可读性严重下降
- **建议**：为按钮添加不透明背景填充，或确保按钮绘制层级在所有背景精灵之上

### 2.2 赛车 HUD

#### C4. 玩家车辆精灵完全缺失
- **现象**：所有赛车截图中均无玩家车辆，摄像头位于隐形车辆后方
- **影响**：玩家无法感知车辆位置、朝向，严重影响操控感
- **建议**：在屏幕底部中央渲染玩家车辆精灵，保持伪 3D 透视

#### C5. 漂移分数显示缺失
- **现象**：尽管游戏有漂移机制，但 HUD 中无漂移分数、连击计数器或漂移相关元素
- **建议**：添加漂移分数/连击显示（建议位置：左下或右下）

### 2.3 分屏/热座/挑战

#### C6. 分屏模式 P2 速度始终显示 0 km/h
- **位置**：右视窗（P2）
- **现象**：P1 速度正常（249-320 km/h），P2 永远显示 0 km/h
- **影响**：P2 玩家无法获得速度反馈
- **建议**：检查分屏模式下 P2 的输入绑定和 HUD 数据源

#### C7. 挑战模式缺少得分显示
- **位置**：挑战模式竞赛界面
- **现象**：核心玩法 "60秒限时刷分" 但无当前得分显示
- **建议**：在 HUD 中添加当前得分（建议位置：右上角）

### 2.4 移动端

#### C8. 游戏界面完全缺少触控操作按钮
- **现象**：赛车画面无方向控制、油门/刹车按钮，移动端无法操控
- **建议**：添加虚拟方向盘/左右箭头 + 油门/刹车滑块

#### C9. "按任意键开始" 对移动端无效
- **现象**：底部提示依赖物理键盘，移动端无键盘
- **建议**：改为 "点击任意赛道开始游戏" + 添加明确的开始按钮

## 三、主要问题（核心体验改进）

### 3.1 菜单界面

| # | 问题 | 建议 |

| M1 | 按钮布局不均衡（6+3，右下空白） | 改为 5+4 或 3×3 网格 |

| M4 | 底部操作提示文字过小 | 增大字号 + 发光/描边效果 |

| M7 | 赛道按钮无悬停/焦点反馈 | 添加 :hover/:active 状态 |

## 五、建议修复优先级

### 第一批：核心可用性（P0）

6. **M5** 菜单背景遮罩 — 菜单可读性基础

8. **M9** 文字描边/阴影 — 通用可读性

### 第三批：体验一致性（P2）

11. **M14-M15** 热座/挑战模式体验

13. **C2/C3** 赛道名称渲染 + 按钮遮挡
