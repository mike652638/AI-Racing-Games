## 三、新发现问题

### NEW-P1：竖屏标题与副标题重叠（540×960 / 768×1024）

- **表现**：副标题顶边进入标题 box 底边 3px（540×960 几何重叠 787px²、768×1024 为 1120px²）；视觉上「经典」二字几乎触碰标题「飙」字底部笔画，标题区显得拥挤不精致。
- **根因**（已定位到 CSS）：`.title-sub` 基础 `margin: -8px 0 28px`（style.screens.css:273）的负上边距是「亲密排版」意图；既有修复分支覆盖了 ≤390px（归零）、max-height:700px（-6px）、max-height:480px（归零），但**竖屏 540×960 / 768×1024 高度 >700px、宽度 >390px，不匹配任何分支**，保留 -8px；同时竖屏下 `--title-fs` = `clamp(28px, 9vw, 64px)`（540 宽下 43.2px）行高增大，-8px 相对余量不足 → 挤入标题 box。
- **修复建议**：`body.portrait-mode .title-sub`（style.interaction.css:257）补一行 `margin-top: 0`（竖屏负边距归零，与 ≤390px 分支同策略）；或基础规则将负边距收为 `-4px` 并依赖 `title-wrap margin-bottom` 控距。修复后需在 540×960、768×1024 复测 overlapTitle=0。

## 四、待优化项 / 优化建议（P3）

1. **320×568 极窄屏布局偏挤**：标题 26px 在 1/4 屏高显得过大、副标题被低高度规则隐藏后标题区视觉空洞；赛道卡高 45px 接近 44px 触控下限。建议该分支 `--title-fs` 再收敛（如 22px）并小幅压缩标题区上下留白。
2. **开始按钮 hover 反馈较弱**：仅边框高亮，与赛道卡的三重反馈（边框+遮罩+预览联动）不一致。建议增加轻微 scale（1.02）或柔光晕，保持 hover 反馈层级统一。
3. **悬停开始按钮时预览不联动**：track-preview 停留在上一选中赛道（当前为有意设计），可在按钮 hover 时重置预览为当前选中赛道以消除「不一致感」。
4. **排行榜文字偏小**：桌面 1280×720 初始态下榜单 11px 字号对比度偏弱（文字 `rgba(255,255,255,.78)` 级），可微调字号/透明度提升可读性。
5. **竖屏榜单默认展开仍占高**：540×960 下三卡堆叠（82px×3 + 工具栏）约 300px，是内容超高主因之一；可考虑竖屏下 master toggle 默认收起（`aria-expanded=false` 起始态按视口分支切换）。
6. **390×844 首屏榜单被裁剪**：需滚动查看榜单（内容超高所致，可接受）；若采纳第 5 项默认收起，此问题同步缓解。
