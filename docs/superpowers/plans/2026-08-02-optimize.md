## 五、关键经验总结

1. **相机 z 同步是伪 3D 生命线**：M3 发现 camera.z 永远为 0 导致 1 分钟后路面坍缩——任何伪 3D 渲染器都必须确保 `camera.z = cameraZ` 同步
2. **合成事件局限**：CDP `dispatchEvent(keydown)` 只触发瞬时按下（音频需真实激活）；持续按住需 `setInterval` 保持
3. **HMR 状态丢失**：Vite 热更新整页 reload 清空 JS 状态，验证时必须重新注入
4. **Window vs Document 事件**：main.ts 挂 `window.addEventListener('keydown')`，合成事件必须 `window.dispatchEvent`（document 不触发）
5. **TDD 红绿分离**：先写失败测试确认缺失，再写最小实现——修复 bug 时先补回归测试
